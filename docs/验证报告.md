## 统计判据与基准

`tests/fixtures/minitab_baseline.json`来源为 Minitab 22.6 交叉量具 R&R、Xbar-R，采集日期 2026-10-23。SHA-256 为：

`08815D5CB98D15D50F4741893875FFAE560B1D88AF53D05F0B9A124D4C2B8E2D`

基准的 sd/studyvar 数组顺序为 GRR、EV、AV、PV、TV。数值判据为`abs(程序值−参考值) <= 1e-11 + 1e-9×abs(参考值)`，ndc 精确比较；Minitab 实测另检查导入测量值的 double 精确相等。该判据只用于跨软件计算回归，不加入用户的目标允许误差。

## 可选 Minitab 实测

需要本机已安装且许可可用的 Minitab 桌面版。常规 CTest、程序生成及导出均不依赖 Minitab。

```powershell
# 同一对象只生成一次，三种顺序实际导入Minitab
powershell.exe -NoProfile -NonInteractive -STA -ExecutionPolicy Bypass -File .\tests\test_minitab_run_order.ps1

# 24种设计、8类场景及额外0/10位小数，共240组生成数据
powershell.exe -NoProfile -NonInteractive -STA -ExecutionPolicy Bypass -File .\tests\test_minitab.ps1
```

同组脚本支持`-Config`和`-BuildDirectory`；批量脚本支持`-BuildDirectory`及小范围检查用的`-CaseLimit`。两者使用 Windows PowerShell 的 STA 自动化环境，新建专属 Minitab 实例并在结束时关闭，不修改 CSV 参考文件。每份`.mtb`命令保留分析设置，便于独立复核。

## 证据位置

- 原生、CLI、导出报告：`build/test-output/`、`build/cli-test-output/`、`build/export-test-output/`。
- 发布校验报告：`build/release-test-output/`。
- 内嵌字体报告：`build/embedded-test-output/embedded-resources.json`；真实单 EXE 验证目录由`build/latest-single-exe-test.json`记录。
- 字体和渲染性能：`build/font-performance/baseline.json`、`build/font-performance/optimized.json`；最终异步预加载的本机 9 轮启动对照为`build/font-performance/startup-selected/startup-benchmark.json`，CPU 和内存在首次可见后 150 ms 采样，不以性能阈值决定功能测试通过与否。
- 批量 Minitab 实测：`build/minitab-live-时间/`；目录指针为`build/latest-minitab-comparison.txt`。
- 同组实测：`build/minitab-same-study-时间/`；目录指针为`build/latest-minitab-same-study.txt`。
- 实测目录保留配置、源矩阵、CSV、Minitab 导入列、统计存储列、命令及 JSON 对比；同组实测还保存未舍入指标对照 CSV。

机器报告绑定被测版本及 EXE 哈希，帮助文案或资源改变后应重新执行相关测试。打包脚本实际运行包内原生/CLI 回归并校验哈希。`build/`中的临时文件和机器报告由`.gitignore`排除；仓库保留测试脚本与必需基准，其他机器可据此重建证据。

## 验证边界

目标环境为 Windows x64。Xbar-R 的 192 组固定基准、240 组生成数据实测和同组三种运行顺序实测，分别采用 Minitab 22.6 的交叉量具 R&R、均值极差法口径。ANOVA 原生计算接口与五软件 GUI 参数组合另有专项记录，不由 Xbar-R 测试结果推断。

当前模型不覆盖 EMP、嵌套、非平衡、固定/混合效应或 REML/ML/MINQUE/Bayesian。其他操作系统、所有设备的显示效果和全部中文输入法场景未获完整验证。显示缩放像素回归与实际窗口流程验收分别记录。

## ANOVA 及五软件扩展验证

ANOVA 计算接口专项执行时，8 项 CTest 通过，CLI 为 101 项检查。ANOVA 专项验证 72 组设计/交互策略生成、216 组运行顺序回读及五种长表字节一致性，包含解析解、零/负分量、概率与 27 组外部软件参考矩阵。该专项构建实际跑完 27 组 × 5 软件，共 135 次对照、5,776 项数值检查；原 Xbar-R 基准独立保留。

软件口径、原生接口范围、误差及本机版本见[ANOVA 设计与五软件对标](ANOVA设计与五软件对标.md)。本地完整证据为`build/anova-software-final/`，`artifact-binding.json`绑定该专项的 GUI、CLI 和外部参考矩阵。GUI 实际完成 ANOVA 启动加载、生成、详情、保存、90 条随机导出及恢复默认，CSV 与 CLI 逐字节一致；记录见`build/latest-anova-gui.json`指向目录中的`verification.json`，个人配置未改变。
