# v1.0.0 同组数据三种运行顺序 Minitab 对标

该试验只生成一次数据，将同一个不可变 Result 对象分别按“不随机化”“随机化所有运行顺序”“操作员内部随机化”导出，再逐份实际导入 Minitab 进行 Xbar-R 分析。三种行序不通过三次生成来替代同一组数据。操作口径见[Minitab 导入与对标](Minitab导入与对标.md)，证据位置见[验证说明](验证报告.md)。

## 研究配置

- 研究设计：3 人×3 次×10 件，共 90 条测量；生成种子 123，保留 4 位小数。
- 配置：`examples/示例配置.json`，LSL=9、USL=11、研究变异倍数 6。
- 导出：Minitab 长表，UTF-8 无 BOM、英文逗号、CRLF，首行为`StdOrder,Operator,Part,Trial,Measurement`。
- 排序种子 321；第三种模式启用“随机化操作员顺序”。每项研究随机确定一次操作员顺序，各 Trial 沿用该顺序，每个 Trial＋Operator 内部独立打乱部件。
- Minitab 用`WOPEN`直接读取原始 CSV，以 Operator、Part、Measurement 执行交叉量具 R&R 的 Xbar-R 分析；Trial、StdOrder 从实际导入列逐条回读。
- Minitab 研究变异倍数为 6，容差为 2，通过存储列及 17 位输出读取完整精度结果；分析命令保存在`.mtb`文件。

## 数据身份、Trial 与 StdOrder

每份 CSV 应满足以下条件：

| 核对项 | 判据 |
|---|---|
| 记录数量 | 每份 90 条，无丢失或重复；每个 Trial 为 30 条 |
| 测量身份 | Operator＋Part＋Trial 与源矩阵一一对应 |
| Measurement | Minitab 回读值与源矩阵按 double 精确相等，CSV 保留 4 位小数 |
| StdOrder | 完整 1～90 排列；标准模式按序输出，随机模式只改变行序 |
| 行序及 Trial | Minitab 保留 CSV 行序，Trial 不得按随机后的行号重新编号 |
| 统计不变性 | 排序不修改源矩阵、生成种子或程序原始统计结果 |

操作员编号 A=1、B=2、C=3 时，StdOrder 按下式独立核对：

```text
StdOrder = ((Trial − 1) × 产品件数 + Part − 1) × 人员数 + 操作员编号
```

将三份文件按 StdOrder 恢复标准序后，完整五列文本的 SHA-256 应相同。固定数据、配置及排序种子应复现同一行序；不要求与 Minitab 相同种子产生完全相同的随机排列。

## 指标对照

比较 GRR、EV、AV、PV、TV 的标准差、研究变异、%Study Var、%Tolerance 及 ndc，共 21 项。程序未单独展示的 PV/TV 百分比与分量%Tolerance，由同一份标准差、倍数和规格范围计算，仅用于对标。GRR 的%Tolerance 即程序 P/T%。

程序与 Minitab 以及三种行序的 Minitab 结果之间，均采用：

```text
abs(程序值 − Minitab值) <= 1e-11 + 1e-9 × abs(Minitab值)
ndc：精确相等
```

该判据不放宽生成约束。完整未舍入的指标表、逐项绝对差及三种行序之间的差异，应从本版本机器报告和`metrics-comparison.csv`读取。

## 复现与证据

```powershell
cmake --build build --config Release --target msa_export_tests
powershell.exe -NoProfile -NonInteractive -STA -ExecutionPolicy Bypass -File .\tests\test_minitab_run_order.ps1
```

测试脚本调用测试程序的`--same-study`入口，只生成一次并连续导出三次。结果目录由`build/latest-minitab-same-study.txt`指向，内容包括：

- `standard.csv`、`all.csv`、`within_operator.csv`：三种行序的原始导出文件。
- `study.json`、`exports.json`：源矩阵、实际参数、程序统计与导出清单。
- `comparison.json`：逐项身份、精度及统计对照，连同被测版本和 EXE 哈希。
- `metrics-comparison.csv`：未舍入指标表。
- `*-minitab-import.txt`、`*-minitab-statistics.txt`及`.mtb`：实际导入列、分析结果和命令。

脚本需要本机已安装且许可可用的 Minitab 桌面版。输出保留在由`.gitignore`排除的本地`build/`目录；源代码中保留测试程序、自动化脚本及配置，可独立复现。
