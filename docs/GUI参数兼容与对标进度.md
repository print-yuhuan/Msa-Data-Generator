# 五软件 GUI 参数兼容与对标记录

本记录保存 v1.0.0 分析参数专项的原生界面实测，区分软件报告、独立公式和程序回归。未取得结果的项目不计为通过；接口自动化结果另见[ANOVA 设计与五软件对标](ANOVA设计与五软件对标.md)，不能替代本记录中的 GUI 实测。后续 UI 或许可文案重新构建不代表这些外部软件案例重新执行。

## 共同数据与口径

- 3 名操作员、10 个部件、3 次重复，共 90 条测量记录；测量保留 6 位小数。
- 长表包含`StdOrder,Operator,Part,Trial,Measurement`，随机行序不改变任何字段对应关系。
- 规格 9～11，研究变异倍数 6；ANOVA 使用随机操作员、随机部件，保留交互模型。
- Part、Operator、Measurement 分别指定为部件、人员、测量值。Trial 及 StdOrder 不作为额外因子。

历史过程案例在置信页实际勾选“包括置信区间”、95%、下限，运行后 Minitab 报告明确注明：“将历史标准差用于计算总过程方差时，置信区间不可用。”因此 63 项只比较原生报告实际显示的数值，没有把本程序历史过程置信限当作 Minitab 对标通过。该组合下本程序的置信限属于数学变换扩展，已有关系回归，不宣称 Minitab 原生提供相同区间。参数、报告证据为本地`minitab-anova-historical-*-ui.png`与`minitab-anova-historical-lower95-ui.txt`。

切换为研究部件过程口径后，原生报告恢复 CI，并保留历史 SD 作为%Process 分母。95%下限案例 GRR 的 SD 下限为 0.028、研究变异下限 0.146、P/T 下限 7.31；99%上限合并模型案例分别为 0.189、0.972、48.62，与本程序按显示精度一致。合并案例同时检查原始完整 ANOVA 表及合并后的表，避免只验证点估计而漏掉残差自由度和模型选择。证据为`minitab-anova-study-history-lower95-ui.txt`、`minitab-pooled-upper99-ui.txt`及各自参数和比较 JSON。

原生界面文字、截图和机器比较分别保存于本地`minitab-*-ui.txt`、`minitab-*-ui.jpg`、`minitab-*-comparison.json`。`compare_minitab_gui.py`只读取该专项保存的 GUI 表格并按显示精度比较，未通过 COM 或其他后台接口生成外部软件结果。

### MATLAB 单侧规格与 5.15 研究倍数补测

重新通过原生文件导入工具读取同一共同 CSV，范围为`A2:E91`，明确指定 Part、Operator、Measurement；选择交互效应、随机操作员、倍数 5.15，仅启用上规格 10.5，下规格为“无”。原生报告确认 10 个零件、3 名操作员、90 次测量，GRR%=10、ndc=14，精度与容差比率 PTR=0。完整表格的方差、贡献率、SD、研究变异、%研究变异及 ANOVA 的 SS/DF/MS/F/P 共 57 项显示精度比较，56 项一致、1 项差异。

差异为 P/T：本程序采用 Minitab 单侧定义，`100×(5.15×GRR/2)/abs(10.5−均值)`，得到 17.166667197440862%；MATLAB 在缺失侧为无穷的规格区间下报告 PTR=0，换算百分比仍为 0。测量数据与 ANOVA 分量一致，差异来自规格口径，不修改测量值或强行改变本程序默认口径来消除差异。该案例按 GUI 显示末位精度比较，不能与前两组完整精度比较混称。结果已加入`gui_parameter_baseline.json`，差异另列；本地保留`matlab-single-upper-515-options-ui.png`、`matlab-single-upper-515-ui.txt`及比较 JSON。

历史 SD 有效时，Origin ANOVA 报告的“部件间”小计仍显示样本 PV（0.33166），其下的 Part 行显示历史 TV 反推的 PV（0.49889）。本程序历史 PV 对应 Part 行。比较时按语义映射，未把两个不同口径的行混作同一指标。Xbar-R 历史报告直接列出调整后的 PV=0.49918。

差异明细：

1. k=6、95%双侧案例：Operator 研究变异上限，Origin 为 0.70556，本程序为 0.7055467657822592，绝对差 1.3234e−5；PV 的 P/T 上限，Origin 为 181.74966，本程序为 181.749667181083，绝对差 7.1811e−6。两项均超出报告末位半单位，没有放宽阈值。
2. 在界面将置信度设为 90%、类型设为上限后，报告表头仍写 95%UCL。GRR SD 上限实际为 0.06415，与本程序 90%单侧结果 0.06414954549466734 一致，明显不同于 95%单侧值 0.08735448456462647；表头与实际计算置信水平不一致。
3. 同一 k=5.15 案例中，Origin 研究变异和 P/T 置信上限的报告值仍与 6×SD 换算一致。例如 GRR 研究变异上限为 0.3849、P/T 上限为 19.24486；本程序按 5.15 倍计算，分别为 0.3303701592975368、16.51850796487684。此换算差异涉及 7 个分量的 14 项检查，不能当作测量数据不一致。单侧案例另有 Operator×Part 方差上限 6.3150e−9 的末位差异。
4. 在 Origin 界面填写历史 SD 后，“包含置信区间”复选框被禁用。无历史 SD 时可启用 CI。历史 SD 与 CI 的组合无法用本次 Origin 原生报告交叉验证；本程序此组合的数学关系测试另行记录。

本地证据为`origin-*-ui.jpg`、`origin-*-comparison.json`；90%上限另保留参数页截图。原生参考值与 17 项差异均保存在`tests/fixtures/gui_parameter_baseline.json`，包含`comparison_count`、`check_count`、`difference_count`，避免将只通过的子集误称为整组通过。

## 程序已补充的参数

GUI、CLI、配置保存/加载与恢复默认共用以下字段，命令行参数优先于配置文件：

| 计算项 | CLI | 说明 |
|---|---|---|
| 独立分析容差 | `--analysis-tolerance` | 优先计算 P/T，不修改生成的规格范围 |
| 单侧规格 P/T | `--lsl`或`--usl` | 半研究变异除以规格到均值的绝对距离 |
| 历史过程 SD | `--historical-sd` | 有效历史 SD 可定义 TV/PV；与参考数据尺度分别控制 |
| 过程估计来源 | `--process-variation` | `historical/study`；有历史 SD 时另报告%Process |
| 历史均值 | `--historical-mean` | 留空使用实际测量均值；用于单侧容差和误分类 |
| 误分类概率 | `--misclassification` | ANOVA 且有规格限；输出两种联合概率与对应条件概率 |
| 置信限 | `--confidence`、`--confidence-level`、`--confidence-bound`、`--confidence-method` | ANOVA 方差分量、SD、研究变异、P/T 及%Process；默认 MLS，可选 Satterthwaite |

置信区间暂不包含%贡献、%研究变异及 ndc 的比值区间。固定操作员的混合效应、REML 和 Bayesian 估计也不应当作当前双随机 EMS 模型直接比较。完整说明见[配置参考](配置参考.md)。
