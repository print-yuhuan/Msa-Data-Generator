# 结果可视化

图表页可查看程序生成的测量数据，也可导入 CSV 或 XLSX。预览、编辑和导出均在本机完成。

## 入口与数据来源

在“图表”页可查看和编辑七种研究图形，也可导入测量数据，导出单图或组合图。

结果图表使用当前选定的数据源：

| 来源 | 使用方式 | 配置与状态 |
| --- | --- | --- |
| 当前生成结果 | 先在数据页获得有效生成结果 | 使用该结果关联的研究配置和统计指标；业务配置变化导致结果失效时不能继续作为当前数据源 |
| 导入数据 | 点击「导入数据」并选择 CSV 或 XLSX | 程序读取文件的研究设计，按当前分析方法计算统计结果 |

CSV 导入上限为 4 MiB，XLSX 为 16 MiB。只有一张数据工作表时自动选中该表，多张时可选择其中一张，包括隐藏的数据工作表。每次只识别选中工作表的人员和数据。工作表中的公式取工作簿保存的计算值。取消或导入失败时保留原有数据和图表。

每份研究须包含 2 或 3 名操作员、5～10 件部件、每人对每件部件测量 2 或 3 次。程序按以下规则读取文件。

| 文件布局 | 操作员和研究设计的识别方式 |
| --- | --- |
| 带标记的宽表 | 左上格可留空，或填写 `Operator`、`操作员`，其右侧为从 1 开始的连续部件编号。首列填写姓名，每人占用连续的两行或三行，按分组顺序显示。 |
| 长表 | 按列名读取 `Operator`、`Part`、`Trial`、`Measurement`。每条测量值按姓名、部件和轮次归位。含 `StdOrder` 时还原标准人员顺序，省略时按姓名在表中首次出现的次序显示。 |
| 没有操作员名称的纯数值宽表 | 按位置使用 A、B、C。4 行对应 2 人各测 2 次，9 行对应 3 人各测 3 次。遇到 6 行时，程序弹窗供选择「2 人各测 3 次」或「3 人各测 2 次」。 |

六行宽表的选择只用于这次导入。取消或关闭弹窗会保留当前数据和图表。多工作表 XLSX 会先让你选表，再根据该表的内容决定是否询问研究设计。选项页里保存的默认操作员和重复测量次数继续用于生成新数据。

导入后可修改分析方法、规格或历史参考，再点击「按当前设置重算」。重算使用导入时的测量矩阵及研究设计。原文件的读数发生变化时，请重新导入。

图例、操作员分布图的横轴、控制图的分面标题均使用本次研究的操作员名称。方法对比报告在「研究设置」列出参与测量的所有操作员。导入后再修改默认名称，原研究仍保留导入时的名称。

## 七类结果图表

| 图表 | 内容 | 解释边界 |
| --- | --- | --- |
| 变异分量 | GRR、EV、AV、PV 的研究变异百分比、方差贡献率；适用时显示公差占比和过程占比 | 沿用当前分析结果的口径；标准差比例、方差比例和公差比例不可混用 |
| 测量值与部件 | 按部件显示各操作员的完整测量点及部件均值 | 点的轻微横向偏移仅用于区分重叠，不改变测量值 |
| 操作员分布 | 各操作员的箱线图与测量散点 | 四分位数采用线性插值；须线延伸至 1.5 IQR 范围内的最远观测值；不声称与所有外部软件的默认箱线定义相同 |
| 极差控制图 | 每个“操作员 × 部件”重复测量子组的极差，按操作员分面 | 所有分面共享全部子组的平均极差、纵轴和传统 D3、D4 控制限 |
| 均值控制图 | 同一子组的均值与控制限，按操作员分面 | 所有分面共享全体测量总均值，采用 A2 × 合并平均极差计算控制限；超限不直接等同于量具不合格 |
| 部件 × 操作员交互图 | 各操作员对各部件的重复测量均值连线 | 展示可能的交互形态，不替代 ANOVA 交互项显著性检验 |
| 测量值直方图 | 所有测量值的等宽分箱频数 | 不包含正态拟合、正态性检验或过程能力结论 |

各图标明分析方法、操作员/部件/重复次数和记录数。ANOVA 图另标明最终交互项处理状态及完整模型的交互项 P 值。交互图和直方图默认按观测值取范围，便于观察相近的操作员均值或测量值的分布。若需与规格对照，可在“图例与线”里打开规格参考线。

控制图默认显示 CL、UCL、LCL，超限子组以放大的红色标记强调，默认点形为方形。极差图用于检查重复测量的一致性。均值图中较多部件均值越过重复性控制限，可能反映量具能区分部件，判定时还应结合 GRR 等指标。

两种分析法的控制图均使用传统 A2/D3/D4 与合并平均极差，研究变异倍数不会替换控制图的三倍标准差原则。该明确口径不自动模拟外部软件的所有默认设置。与 Minitab、Origin、JMP、SPSS 或 MATLAB 比较时，须对齐子组定义、控制限估计方法、箱线图四分位数算法及规格参考线；尤其不能将 MATLAB 按连续记录分组的默认图与随机行序直接比较。

### 图表编辑

选择图表类型，点击“编辑图表”。编辑时预览会随有效输入更新，并标记“草稿预览”。点击“应用编辑”采用该样式，再导出即可得到同样的点形、颜色和坐标设置。每种图表有自己的草稿，收起编辑器或切换图表后可回来继续修改。

| 编辑分组 | 可以调整的内容 |
| --- | --- |
| 坐标轴 | 标题、横纵轴名称、纵轴上下限和主刻度目标间隔数。间隔数留空时自动计算，填写 2～10 可调节疏密。实际刻度还会适配画布高度和频数的整数单位。 |
| 图形 | 主色及适用于当前图形的线宽、点大小和点形。选择按系列区分点形后，交互图上的操作员可通过方形、圆形和三角形识别。直方图可输入 3～40 调整等宽分箱数，留空恢复自动。 |
| 图例与线 | 按图种切换图例、网格、控制限或规格参考线。显示图例时可将它放在绘图区上方或下方。 |

纵轴上下限留空时自动计算，填写时下限须小于上限。输入尚未完成或超出范围时，预览回到已应用的样式并给出提示。可修正输入，或点击“撤销草稿”回到上次应用的设置。导出前，请应用或撤销所选图表的草稿。“重置当前图表”恢复当前图的默认外观，“重置全部图表”恢复七图的默认外观，并保留组合选择。

图表编辑只影响显示和导出，不修改测量数据、统计结果或生成约束。不同图表分别保留编辑值。样式、组合勾选、图表格式和分辨率在当前会话保留。图表导出目录、图表导出名称和静默开关随“保存配置”保留到下次启动。

当大数据中心与微小变异同时出现时，坐标轴可显示明确的数值偏移说明。缩窄纵轴范围会裁剪图形，不把超出范围的数据强制贴到边界上。

## 图表导出

在“图表导出”选择格式、范围和分辨率，然后使用底栏导出操作。

格式与输出范围直接显示为选择按钮；组合中的图表使用复选框，可全选或清空。测量数据导入目录、图表导出目录及相应名称统一在「选项 → 文件 → 目录与文件名」设置。

| 设置 | 选项与行为 |
| --- | --- |
| 格式 | PNG、JPEG、PDF、SVG |
| 范围 | 当前单图，或勾选图表组合 |
| 组合布局 | 单列纵向组合或两列组合；按图表清单顺序排列，未勾选图表不导出 |
| 单图分辨率 | 1200、1800 或 2400 像素宽；保持比例缩放，不拉伸图形 |
| 文件名 | 默认为 `MSA_Charts`，程序按所选格式补充扩展名 |
| 目录 | 留空使用系统桌面，相对路径从桌面计算，也可选择其他文件夹 |
| 同名文件 | 静默保存时自动追加 `_1`、`_2` 等序号；在“另存为”中可确认替换 |

需要放大、排版或在矢量编辑器里调整文字与线条时，选择 **SVG**。单图和组合 SVG 都保留文字、线段和标记，字号和边距随画布等比例缩放。查看 SVG 时由阅读器选用本机中文字体。PNG、JPEG 和图表 PDF 使用程序内嵌字体绘制。图表 PDF 将所选图排在同一页，页面物理尺寸由画布和分辨率决定。

组合支持全选、清空和已选数量提示；零张时禁用导出。导出在后台进行，使用开始导出时的数据与已应用样式快照。默认点击“导出图表”打开“另存为”。在「选项 → 文件 → 导出方式」开启“静默导出图表”后直接保存。成功后可用“上次导出目录”打开实际文件夹。失败原因和恢复操作显示在页内，细节记入日志。

预览生成失败时可重试渲染、重置当前图表或切换数据源；相同错误不在每帧重复刷日志。文件名、目录、图元、画布规模和输出参数在编码前校验；写入或编码失败可修正设置后重试。导入失败保留原有数据。底栏位置固定，页内错误说明随正文滚动。

## 双方法对比报告

在图表页选中生成结果或已导入的数据后，点击“导出方法对比报告”。报告列出研究设计、数据来源、EV/TV、AV/TV、GRR/TV、P/T、ndc、两种方法各自的 TV 来源、有效容差、交互项策略和最终模型。生成研究另列数据种子，导入研究列出源文件名。第二部分是这组记录的极差图和均值控制图，打印时另起一页。

在「选项 → 文件 → 导出方式」设置“方法对比报告默认格式”。同一子页的“目录与文件名”可设置报告目录和文件名。HTML 可直接在浏览器打开和打印。默认格式 PDF 使用本机 Microsoft Edge 或 Google Chrome 后台生成，保留可检索文字和矢量控制图。

报告默认弹出“另存为”，预选配置的格式，可在该窗口更换文件类型、文件名和位置。开启“静默导出方法对比报告”后，将按已设置的名称直接保存，默认名称为 `MSA_Comparison.html` 或 `MSA_Comparison.pdf`，遇到同名文件自动追加序号。报告目录留空时使用系统桌面，可填写桌面下的相对目录或选择其他文件夹。成功后可在日志查看实际路径。

CLI 在生成和已有数据分析两种模式下均接受 `--comparison-report PATH`。指定 `.pdf` 时生成 PDF，指定 `.html` 时生成 HTML。[命令示例](使用说明.md#比较研究与还原导出)

## CLI 范围

图表编辑和 PNG、JPEG、PDF、SVG 图表导出由桌面界面提供。CLI 可导出构图所需的 CSV/XLSX 数据、JSON 结果和双方法对比报告。
