# 代码审查修复与回归

日期：2026-10-30。版本：**v1.0.0**。本次处理完整审查确认的七项问题，保留现有功能。对应代码及文档纳入唯一初始提交，Windows x64 发布包使用本文列明的最终构建；Release 不另上传源码包。

## 修复范围

| 问题 | 修复方式 | 回归覆盖 |
|---|---|---|
| MLS 低置信水平丢失区间方向 | 配置归一化和直接计算入口共享有效域校验。超出当前 MLS 近似有效域时明确拒绝，并提示最低水平；需要更低水平可显式选择 Satterthwaite，不自动切换算法 | 两种人数、单/双侧边界、配置与 GUI 转换、直接计算、Satterthwaite 解析解及默认 95% 控制案例 |
| 固定字体图集满后新字形消失 | 改为多页图集及有界 LRU，绘制前重新获取失效的页坐标，换页和上传前提交旧批次；不同 OpenGL 上下文独立管理纹理 | 单个文本的 20,000 个不同汉字、分页、超预算淘汰、旧布局、保留层重建、多上下文、释放重建及回退字体几何 |
| 源码包包含被忽略的本地文件 | 采用 Git 文件清单和目录白名单，保留当前工作区修改；拒绝链接越界，先写临时归档，失败保留原包 | 中文路径、嵌套忽略规则、新增/修改/删除源码、许可、SHA-256、损坏清单和替换失败回退 |
| Minitab 脚本误判单侧 P/T | 移除“非双侧时必须为空”的过期断言，共享比较判据；明确记录已比较、未比较和不适用 | 双侧一致/差异、单侧、独立容差、无规格以及缺失或非有限结果；本地判据回归不启动 Minitab |
| 合法长文件名不能保存 | Windows/POSIX 同目录临时文件不再拼接目标 basename，保留原子提交与不覆盖语义 | 255 字符文件名组件、251 字符名称自动追加序号、并发不覆盖及临时文件清理 |
| 解读会话清除生成建议 | 解读发送和新建解读会话保留生成诊断；新生成请求或新建生成会话才清理对应状态，研究变更仍作废过期建议 | 实际异步发送、成功/失败回复、发送前失败、建议按钮保留、新建会话及修订号保护 |
| 键盘菜单错误扣除全页滚动偏移 | 沿控件真实祖先累加滚动变换，每层按物理像素对齐；固定导航不受正文滚动影响 | 固定帮助导航、单层/嵌套滚动、Enter/Space、鼠标及四档 DPI |

字体图集的 **32 MiB** 是 CPU 常驻像素缓存预算；提交时可暂时持有一个已淘汰页。GPU 纹理预算为每个 OpenGL 上下文 32 MiB。这些数值不是整个进程的内存上限，不包含字体原文件、布局、映射元数据和临时栅格位图。详情见[字体图集设计与验证](字体图集设计与验证.md)。

MLS 限制、单侧 P/T 和文件命名规则已同步至[使用说明](使用说明.md)、[配置参考](配置参考.md)、[Minitab 导入与对标](Minitab导入与对标.md)，并更新程序帮助和 CLI `--help`。AI 状态规则见[AI 协议与错误恢复](AI协议与错误恢复.md)，归档范围见[源码打包规则](源码打包规则.md)。

## 验证方法

Windows x64 Release 构建，启用 `MSA_BUILD_RENDER_TESTS=ON`，运行全部 CTest；字体测试使用真实 OpenGL 隐藏窗口与帧缓冲像素比较。AI 使用回环模拟服务和假凭据，不读取个人密钥或访问真实 AI 服务。

```powershell
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure --timeout 180
python tests/test_analysis_reference.py --cli build/Release/msa_cli.exe --input build/gui-audit-20261025/common.csv --output-directory build/review-fixes/scipy-reference
python tests/test_chart_files.py --directory build/chart-test-output
```

SciPy 补测输入为此前留存的共同数据；常规 CTest 的统计基准和隔离夹具都在仓库内，不依赖该本地证据目录。新增字体、会话、源码包和 Minitab 判据测试已注册到 CTest。

- 长文件名的运行测试平台为 Windows；POSIX 临时名称路径已同步修改，未在本轮运行 Linux/macOS 测试。
