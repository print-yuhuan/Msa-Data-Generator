# 文档导航

本目录对应 MSA 数据生成器 **v1.0.0**。使用指南描述当前功能；验证记录只证明其列明的数据、参数、软件版本与构建，不将部分案例扩展为全部兼容结论。

v1.0.0 当前发布包含结果可视化、AI 助手及 2026-10-30 的七项审查修复。图表与 AI 分别提供专项验证记录；本次完整回归见[代码审查修复与回归](代码审查修复与回归.md)，历史验证仍按原构建和参数范围阅读。

## 阅读验证记录

报告中的日期、二进制哈希和检查数量对应各自被测构建。重新构建后应重新执行适用的回归，不能把历史软件实测转记为新二进制的实测结果。`build/` 中的逐组 CSV、软件原生报告、JSON 和临时截图属于本地证据，由 `.gitignore` 排除；仓库保留复现脚本、必需参考矩阵及文档引用的截图。
