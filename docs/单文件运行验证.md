# 单文件运行验证

`msa_generator.exe` 内嵌完整 Noto Sans CJK SC 字体、应用图标及窗口清单。字体以无损分块压缩的 `MSA_FONT_NOTO_CJK` RCDATA 资源保存，启动时在后台解码至共享内存，再由界面线程注册和绘制。文件名、路径和其他动态中文文本使用同一字库。

## 自动化回归

启用桌面测试后运行以下命令。

```powershell
cmake -S . -B build -A x64 -DMSA_BUILD_RENDER_TESTS=ON
cmake --build build --config Release --parallel 6
ctest --test-dir build -C Release -R msa_embedded_resources_regression --output-on-failure
```

内嵌资源回归覆盖容器损坏拒绝、完整字体字节、共享内存生命周期、重复注册、度量缓存逐出，以及不同字号的中文度量与 OpenGL 像素。源字体文件用于对照验证。报告位于 `build/embedded-test-output/embedded-resources.json`。图集分页、缓存预算及像素回归见[字体图集设计与验证](字体图集设计与验证.md)。

## 窗口验收

1. 将 `msa_generator.exe` 单独复制到一个新建中文目录。指定另一个空工作目录，从该目录启动程序。
2. 使用独立测试配置载入示例，生成 3 人 × 3 次 × 10 件部件的测量数据。检查应用图标、中文标签和复核结果。
3. 切换 Minitab 长表，选择全部随机化并保留 StdOrder，以包含 `龘`、`𠮷` 的文件名导出。核对 90 条数据、标准序号与测量值精度。
4. 使用相同配置及实际生成种子，在其他目录用 CLI 生成对照文件，比较 CSV 字节。检查程序和工作目录未写入临时字体。

主程序运行需要 Windows x64 和支持 OpenGL 3.3 Core 的图形环境。用户配置与导出文件按应用设置保存。便携运行包随附 `LICENSE`、`NOTICE`、`licenses/` 和第三方声明。再分发时请保留适用许可材料。
