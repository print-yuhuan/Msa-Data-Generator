# v1.0.0 最终验收与发布

验证日期：2026-11-09。平台：Windows x64、Visual Studio C++、GLFW / OpenGL。产品版本为 **v1.0.0**，界面框架为 **EUI-NEO 0.6.2**。

本页记录 v1.0.0 的审查基础、当前正式构建回归与发行验证，并区分框架升级阶段和状态指示器、选项分组调整后的实际窗口检查。所有研究数据、统计计算、图表渲染和导出均在本机完成。历史五软件对标记录保留各自的日期、构建与适用范围，不作为本轮重新操作五款软件的证据。

## 审查与清理

在本地工具清理及 EUI-NEO 0.6.2 升级阶段，完整阅读 62 个自有代码文件，共 18,311 行（含空行和注释），并审查 EUI 本地差异、升级集成、构建配置、资源模板、配套脚本和文档。该数量对应这一阶段，不代表后续新增文件也计入该逐文件统计。第三方原版依赖检查版本、许可和集成风险；未将全部第三方源码列为逐行深审。

本轮确认的问题均已处理：

| 类别 | 问题与修复 | 验证 |
| --- | --- | --- |
| 数值健壮性 | 极端测量值下，有限标准差的平方可能溢出；现在对派生统计量执行有限值校验，明确报错并保留原有报告 | 内核及 CLI 回归；失败退出和原报告保护 |
| 置信区间 | 极端单位下均方的再次平方可能上溢或下溢；仅在极端范围归一化计算，再恢复原方差单位 | 24 组尺度组合、1,008 项端点及状态检查 |
| 独立验证 | SciPy 核对脚本未完整处理负方差截断和不同研究设计；补齐无效区间状态比较、设计权重与可选 `--config` | 两种设计各 352 项，共 704 项 |

在上述范围内没有确认尚未处理的致命、严重或一般级运行缺陷。此结论不代表任意输入、全部硬件和所有第三方实现都已穷尽验证。

EUI 本地补丁以 `6fc68e1b660c9d83ebe83ed442f86b7ebba4cc04` 为基准，包含 18 个本地变更文件。字体保留多页图集、LRU、旧字形恢复、多上下文隔离和像素对齐，并接入上游按需分配、局部上传和前进量缓存；图像与保留层采用流式顶点上传，补齐发布复验发现的偶发合成空白问题。补丁可在固定基线应用，检查方法及范围见第三方组件说明。

## 复现与证据

```powershell
cmake -S . -B build-local -A x64 -DMSA_BUILD_RENDER_TESTS=ON
cmake --build build-local --config Release --parallel 4
ctest --test-dir build-local -C Release --output-on-failure
python tests/test_chart_files.py --directory build-local/chart-test-output
.\scripts\package.ps1 -BuildDirectory build-local
```

本地详细审查、逐文件覆盖清单与完整日志分别保存在 `outputs/code-review-report-2026-11-09.md`、`outputs/review-coverage-20261109.json` 和 `build-local/final-20261109/`。这些工作记录、个人配置备份及构建缓存由 `.gitignore` 排除；发行包只包含必要的程序、文档、示例、许可和包内校验结果。

状态指示器、选项分组及图层合成修正的发布复验位于 `build-local/publish-ui-20261109/`，包含最终构建日志、字体绘制覆盖专项、完整 CTest 和受控对照记录。图层空白问题的诊断与修复边界见[字体图集设计与验证](字体图集设计与验证.md)。本地集成补丁对 18 个文件完成了反向还原、正向应用检查及应用后内容一致性核对。

本轮没有重新操作五款外部软件的全部参数组合，没有运行非 Windows 平台、SDL2 或 Vulkan 后端。PDF 为高分辨率图像页面；文字不可搜索。未根据功能测试结果声称启动速度或帧率获得特定提升。
