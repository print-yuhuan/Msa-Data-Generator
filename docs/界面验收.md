# 界面验收

使用独立测试配置和输出目录，按下列清单核对预期行为。记录被测程序、Windows 版本、显示缩放和工作区大小。自动化入口见[验证说明](验证报告.md)，布局和状态约定见[界面设计规范](界面设计规范.md)。

## 布局与交互约定

- 主导航为“数据、图表、日志、选项、帮助、关于”。选项分为“研究、分析、导出”；帮助分为“快速入门、分析指标、导出顺序、文件变量、命令说明、结果图表”。
- 默认客户区以 1280 × 820 逻辑像素为目标，根据 DPI、界面缩放及主屏可用工作区适配，并在首次显示前居中。常规最小客户区为 620 × 500 逻辑像素，可用工作区不足时继续缩小。标题栏与边框不计入逻辑客户区尺寸。
- 数据生成页与选项分类在宽窗口下采用两栏；以滚动区可用内容宽度为准，数据页小于 1080、选项页小于 1100 时改为单栏。常规控件高 40，固定底部状态与操作区高 64；正文独立滚动并预留滚动条宽度。
- EUI-NEO 页签、分段选择器、开关、单选按钮、复选框、步进器、数据表格和进度条按任务使用。局部控件状态过渡约为 120～180 毫秒，遵循 Windows 界面动画偏好；正文不使用位置或缩放动画。
- 生成、保存、导出、复制等操作的反馈保持在原有区域；成功提示使用底部状态栏，不弹出全局通知，不因提示内容改变页面布局。

## 验收流程

| 项目 | 操作 | 核对内容 |
|---|---|---|
| 初始窗口 | 在常用工作区和显示缩放下首次启动 | 工作区足够时客户区符合 1280 × 820 逻辑像素目标；不足时适配工作区；外框居中、避开任务栏，主导航与底部操作可见 |
| 初始内容 | 载入独立示例研究配置 | 复核区无结果时显示占位符；标题、间距、控件高度协调，底部操作区位置稳定 |
| 页面导航 | 依次打开六个主页面及选项、帮助分类 | 当前项清晰；页签和分段控件的选中、悬停、焦点状态可辨认；切换后无残留菜单或全页闪烁 |
| 选项分组 | 依次检查“研究、分析、导出” | 研究设计、生成规则、生成参数、约束与搜索分别归组。分析方法、评价口径、历史过程参考、统计推断各成一组。导出分为 CSV 格式、文件保存、运行顺序。三个子页共有配置管理 |
| 小窗口与缩放 | 缩小到常规最小窗口，并检查 125%、150%、200% 等显示缩放场景 | 两栏按宽度改为单栏；中文及数字不重叠，控件不越界；内容可滚动，底部按钮不被遮挡；不足以容纳常规最小值的工作区可继续适配 |
| 单文件运行 | 仅复制 msa_generator.exe 到无 resources、字体或其他程序的空目录，再从其他工作目录启动 | 中文、图标、生成和 CSV 导出正常；不解压临时字体；分发压缩包仍保留许可证文件 |
| 数据生成 | 生成 3 人×3 次×10 件数据 | EV/TV、AV/TV、GRR/TV、P/T 及 ndc 与实际结果一致，生成/重新生成不引起全页闪动 |
| 取样与筛选 | 切换五种部件取样，启用近似正态筛选和最低部件跨度后生成 | 默认取样配合空跨度与固定种子可以复现。已启用的筛选同时生效，缺少双侧规格时能看到最低部件跨度的填写要求 |
| 实时缩放 | 拖动四边及四角连续改变窗口尺寸 | 内容随窗口重排，新增区域及时绘制，不出现等待松开鼠标才刷新的黑区 |
| 滚动清晰度 | 在顶部和底部之间滚动 | 文本及控件边界清晰；固定底栏不随内容位移 |
| 过渡与减少动画 | 切换页签、操作开关/单选/分段控件，展开搜索预算；关闭系统动画后重新启动 | 控件短过渡响应及时，无正文位移或缩放模糊；关闭系统动画后减少过渡；不因动画重排整个页面 |
| 键盘与输入 | 使用 Tab/Shift+Tab、Enter/空格、方向键操作页签与控件，输入中文路径 | 焦点可见且顺序合理；键盘操作与鼠标一致；禁用控件不接受修改，中文输入不丢失 |
| 默认 CSV | 选择默认格式并导出 | UTF-8 BOM、CRLF，保留产品列号与人员字母标记，测量值按配置小数位输出 |
| 五种长表 | 切换 Minitab、SPSS、JMP 19、Origin、MATLAB 并导出 | 完整测量记录一致，无 BOM，英文逗号、CRLF；Trial 保留真实重复编号 |
| 运行顺序 | 依次选择三种模式，设置排序种子及 StdOrder | 仅改变完整记录的行序；默认宽表禁用这些控件并解释原因 |
| 运行顺序种子 | 留空，依次切换全部随机化、操作员内随机化、标准顺序及默认宽表 | 两种随机化模式启用输入框，即时显示“选填正整数，留空自动选取”。标准顺序及默认宽表禁用输入框，即时显示“随机化时可用” |
| 数据预览 | 切换复核/预览 | 预览保留配置小数位，复核百分比按界面精度显示；预览标签不误写入长表 |
| 分析详情 | 分别生成 Xbar-R 和 ANOVA 结果，打开第三个结果页签 | Xbar-R 显示“分析详情”并可查看计算口径与分量；ANOVA 显示“ANOVA 详情”；内容与所选方法及结果一致 |
| 配置保存及加载 | 修改研究和输出设置、保存、关闭并重启 | 保存后底栏简短提示，重新启动恢复已保存值 |
| 输出设置独立性 | 只修改导出目录、模板、格式或同名策略 | 已生成结果仍可导出，无需重新生成 |
| 同名处理 | 同一路径分别启用追加序号与覆盖 | 序号模式保留原文件；覆盖模式写入新内容；不弹格式选择窗口 |
| 帮助主题 | 依次查看六个帮助主题并使用内页跳转 | 主题切换后可从顶部阅读。快速入门说明取样、跨度和搜索失败的排查方法，相关入口可直达研究、日志、分析、导出或图表页面 |
| 模板变量复制 | 在“帮助 → 文件名变量”点击英文或中文变量名 | 复制包含方括号的名称，底栏提示成功，无全局弹窗或布局变化；时间戳仍列在毫秒下方 |
| 后台任务及取消 | 启动长搜索，切换日志页后取消 | 主界面保持响应，显示尝试数和取消状态；取消后可再次生成 |
| 默认目录 | 将输出目录留空后导出 | 写入默认配置目录，底栏显示结果 |
| 关于与许可 | 查看关于页的应用图标、版本/许可标签及图标列表卡片，复制版本信息并打开许可目录 | 版本为 v1.0.1，许可标识为 MIT。作者与仓库信息可读，许可全文随运行包提供，复制成功提示位于固定底栏 |

## 文件复核

验收输出应通过独立回读核对记录数量、Operator/Part/Trial 映射及测量值精度。相同研究配置及实际生成种子下，GUI 和 CLI 应生成相同数据；相同导出配置下核对 CSV 一致性。运行顺序与 Minitab 的统计核对见[Minitab 导入与对标](Minitab导入与对标.md#重复执行实测)。

CSV 默认宽表含标签行和人员标记，不按纯数值矩阵读取；长表按列名读取。测试后核对个人配置未被改动，并关闭专属测试进程。
