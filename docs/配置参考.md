# 配置参考

适用版本：v1.0.0；配置格式：`schema_version=1`。

GUI 与 CLI 共用 JSON 配置。默认用户文件为`%USERPROFILE%\MSA数据生成器\msa_generator.json`；GUI 点击“保存配置”才写入，CLI 正常运行仅读取。完整示例见[examples](../examples/README.md)，命令行参数见[使用说明](使用说明.md#cli)。

缺少字段按内置默认值补齐；未知字段、无效类型、枚举或范围会报错。JSON 布尔值写`true/false`，数字不加引号，空值写`null`。CLI 对应的`none`只用于指标参数语法，在 JSON 中用`null`表示不约束。

## 研究、规格与分析

| 字段 | 类型 / 默认值 | 范围及含义 |
|---|---|---|
| `schema_version` | 整数，`1` | 当前仅支持 1 |
| `design.operators` | 整数，`3` | 操作员数量，2 或 3 |
| `design.replicates` | 整数，`3` | 重复测量次数，2 或 3 |
| `design.parts` | 整数，`10` | 部件数，5～10 |
| `analysis.method` | 字符串，`crossed_xbarr` | `crossed_xbarr`均值极差法，或`crossed_anova`方差分析法 |
| `analysis.percentage_basis` | 字符串，`sd_over_tv` | 100×分量 SD/TV_SD，当前固定 |
| `analysis.interaction` | 字符串，`auto` | `auto`按 P 值自动判断，`include`保留，`exclude`合并到误差；仅 ANOVA 生效 |
| `analysis.interaction_alpha` | 数字，`0.05` | 严格 0<α<1；自动模式 P≥α时合并交互 SS/DF |
| `analysis.study_multiplier` | 数字，`6` | 0.000001～100；用于研究变异和 P/T |
| `analysis.tolerance` | 正数或`null` | 1e−12～2e12；独立分析容差，填写时优先作为 P/T 分母，不改变生成规格 |
| `analysis.historical_sd` | 正数或`null` | 1e−12～1e12；历史过程标准差，单位为 1σ |
| `analysis.historical_mean` | 数字或`null` | −1e12～1e12；单侧 P/T 及误分类使用的均值，留空取实际测量均值 |
| `analysis.process_variation` | `historical` | `historical`使用有效历史 SD 估计 TV/PV，`study`保留研究部件估计 |
| `analysis.misclassification` | 布尔，`false` | ANOVA 且至少有一个规格限时计算正态模型的误分类概率 |
| `analysis.confidence.enabled` | 布尔，`false` | ANOVA 方差分量置信区间开关 |
| `analysis.confidence.level` | 数字，`95` | 置信水平百分数，0.01～99.99；启用 MLS 时还须满足下文的算法有效范围 |
| `analysis.confidence.bound` | `both` | `both`双侧，`lower`单侧下限，`upper`单侧上限 |
| `analysis.confidence.method` | `mls` | `mls`为 Minitab 的 MLS 口径，`satterthwaite`为 JMP EMS 的有效自由度近似；仅改变区间，不改变点估计 |
| `specification.lsl` / `usl` | 数字或`null`，默认`null` | −1e12～1e12；双侧规格必须 USL>LSL |
| `specification.compliance` | 字符串，`strict` | `strict`严格规格；`relaxed`允许超规格 |

严格模式至少需要一个规格限；P/T 约束需要规格限或独立分析容差。初始配置的规格限和参考尺度均为空，应填写后生成，或加载可直接运行的示例。

P/T 的有效分母依次取独立分析容差、双侧规格宽度、单侧规格到均值距离的两倍；单侧距离为零时不可计算。历史均值留空时使用测量数据均值。独立分析容差只改变分析口径，严格生成仍使用`specification.lsl/usl`。

历史 SD 不小于 GRR 且选择`historical`时，TV 取历史 SD，PV 取`sqrt(TV²−GRR²)`；否则保留研究估计。`study`模式仍输出分量 SD/历史 SD 的`process_pct`。误分类单独使用有效历史过程波动，不受该选择影响。参考生成尺度留空时可由历史 SD 补足。

报告`metrics.study`保存实际口径及各分量；`metrics.misclassification`的四项概率分别为不合格且被接受、合格且被拒绝，以及以不合格/合格为条件的对应概率，数值范围 0～1。条件事件概率为零时条件概率为`null`。

`metrics.confidence`保存方差分量、SD、研究变异、P/T 及%Process 的置信限。重复性采用卡方区间，其他分量默认采用 MLS 近似，可切换为 Satterthwaite 近似；单侧区间未指定的一侧为`null`。Satterthwaite 有效自由度为`(Σc×MS)²/Σ((c×MS)²/DF)`，报告另存`effective_df`，使用非整数自由度的卡方分位数。零估计或极小自由度可能使上限不可计算；负方差被截断后，不输出无法按原线性组合解释的组合量区间，以`null`表示，界面显示“—”。该输出暂不包含%贡献、%研究变异及 ndc 的比值置信区间；不能以方差分量区间简单相除代替这些区间。

当前 MLS 平方根近似要求系数 `g=1−DF/χ²(1−tail,DF)` 非负。最低有效水平由研究设计中最小的操作员自由度决定；以下为向上取六位小数后可直接填写的最低值：

| 操作员数 | 双侧区间 | 单侧下限或上限 |
|---|---:|---:|
| 2 | 36.537899% | 68.268950% |
| 3 | 26.424112% | 63.212056% |

GUI、CLI 与直接分析共用校验。低于有效范围时明确报错，不输出错误区间，也不自动切换算法；可提高置信水平，或明确选择支持 0.01～99.99% 的 Satterthwaite。默认 95% 的 MLS 行为保持不变。未启用置信区间或使用 Xbar-R 时，这项算法限制不阻止保存尚未使用的设置。

JMP 历史均值单侧案例的 P/T 与本程序一致，但其研究变异列显示半倍数（5.15 变为 2.575）；比较研究变异列时需换算。已核对的 JMP 历史参数误分类报告仍采用样本过程，其四项概率与本程序启用历史均值/SD 的结果不同；当前没有按软件自动切换误分类口径。JMP 95%方差分量区间须选择`satterthwaite`才与已核对的 JMP 报告一致；MLS 为默认算法。

历史 SD 用于定义总过程方差时，本程序仍提供由历史 TV 与 GRR 区间变换的置信限；这是本程序的计算扩展。本机 Minitab 原生报告明确提示该组合的置信区间不可用，Origin 在填写历史 SD 后禁用 CI 选项，因此该扩展不能标为已与两款软件原生 CI 对标一致。另需注意，MATLAB 在缺失一侧规格时使用无穷区间，本次原生报告 P/T 为 0，与本程序按均值到单侧规格距离计算的口径不同。实测范围见[GUI 参数兼容与对标进度](GUI参数兼容与对标进度.md)。

## 生成与搜索

| `generation`下的字段 | 默认值 | 范围及含义 |
|---|---|---|
| `center` | `null` | 数据中心，−1e12～1e12；空值由程序安排 |
| `priority` | `center` | `center`中心优先；`indicators`指标优先 |
| `scale_mode` | `auto` | `auto`自动；`reference_tv_sd`使用参考 TV_SD |
| `reference_tv_sd` | `null` | 1e−12～1e12；缺少双侧规格或指定参考尺度时填写，可由历史 SD 补足 |
| `decimal_places` | `4` | 0～10 整数；生成量化、预览、CSV 使用该精度 |
| `seed` | `null` | 有符号 64 位整数或自动种子；控制测量数据生成 |
| `max_attempts` | `5000` | 1～1000000 整数，最多候选次数 |
| `timeout_seconds` | `30` | 0.01～3600 秒，搜索时限 |

固定生成种子在相同程序版本、相同生成配置且未受超时截断时可复现。种子为空后重新生成可能得到不同数据；搜索失败、超时或次数耗尽不等于数学上无解。

## 指标约束

`targets`有五个固定键：`EV_pct`、`AV_pct`、`GRR_pct`、`PT_pct`、`ndc`，默认全部`null`。百分比口径为 SD/TV；P/T 按上文的有效容差口径计算。

| 约束 | JSON 示例 |
|---|---|
| 不约束 | `"EV_pct": null` |
| 目标值，用默认误差 | `"EV_pct": {"mode":"target","value":10}` |
| 目标值，显式误差 | `"EV_pct": {"mode":"target","value":10,"tolerance_pp":0.1}` |
| 区间 | `"GRR_pct": {"mode":"between","min":10,"max":20}` |
| 不高于 | `"AV_pct": {"mode":"at_most","value":10}` |
| 不低于 | `"ndc": {"mode":"at_least","value":5}` |
| ndc 目标值及零误差 | `"ndc": {"mode":"target","value":14,"tolerance":0}` |

`target_defaults.percentage_tolerance_pp`默认 0.1，范围 0～1000，单位百分点；`target_defaults.ndc_tolerance`默认 0，范围 0～1000000 整数。显式误差仅适用于`target`模式，0 表示零误差；其余模式不额外叠加目标误差。

EV/AV/GRR 的阈值或区间范围为 0～100，P/T 为 0～1000000，ndc 为 1～1000000 整数。显式`tolerance_pp`为 0～1000000，ndc 的`tolerance`为 0～1000000 整数。区间须 min≤max。不同模式的字段不能混用。满足生成约束不等于测量系统合格。

## 输出与运行顺序

| 字段 | 默认值 | 含义 |
|---|---|---|
| `output.directory` | `""` | 空/相对目录以用户默认配置目录为基准；不存在时创建 |
| `output.filename` | `msa_data.csv` | `.csv`文件名模板；全部变量见[使用说明](使用说明.md#导出文件名变量) |
| `output.existing_file` | `number` | `number`同名追加序号；`overwrite`原子覆盖 |
| `output.format` | `default` | `default/minitab/spss/jmp19/origin/matlab` |
| `output.encoding` | `utf-8-sig` | 按格式归一化：默认宽表为`utf-8-sig`，五种长表为`utf-8` |
| `output.run_order.mode` | `standard` | `standard/all/within_operator` |
| `output.run_order.randomize_operators` | `false` | 仅`within_operator`生效，一项研究确定一次人员顺序，各 Trial 沿用 |
| `output.run_order.seed` | `null` | 独立排序种子；1～9223372036854775807 整数或自动选择 |
| `output.run_order.store_standard_order` | `false` | 长表首列是否增加 StdOrder |

默认宽表带产品列号和人员标记，运行顺序字段不参与排版；GUI 中相应控件禁用。五种长表共用`Operator,Part,Trial,Measurement`四列；勾选标准序时为`StdOrder,Operator,Part,Trial,Measurement`五列，行序即实际运行顺序。详情见[导入与对标](Minitab导入与对标.md)。

```json
{
  "output": {
    "directory": "",
    "filename": "MSA_[DATETIME]_[SEED].csv",
    "encoding": "utf-8",
    "existing_file": "number",
    "format": "minitab",
    "run_order": {
      "mode": "within_operator",
      "randomize_operators": true,
      "seed": 321,
      "store_standard_order": true
    }
  }
}
```

修改导出字段不要求 GUI 重新生成；生成参数和指标仍来自已有结果的配置。文件名中的`[SEED]`是实际**数据生成种子**，不是排序种子。CLI 每次执行均创建研究；需要跨进程复现随机长表时同时固定两个种子。

展开后的 CSV 文件名最多为 255 个 UTF-16 代码单元，包含扩展名及自动追加的序号；接近上限时应为序号留出空间。原子写入在同一目录使用独立短临时名称，不额外占用目标文件名的长度预算，保留并发不覆盖保护。

## CLI 覆盖规则

优先级为内置默认值→配置文件→命令行；重复参数最后一次生效。CLI 的指标参数整项替换旧约束，`null`清空可选数值、`true/false`显式开关。`--no-config`跳过用户配置，但不改变空/相对输出目录的基准。

显式`--output`按完整路径字面使用，不展开变量，不使用配置中的路径、模板及同名策略；格式和运行顺序仍按最终配置。覆盖显式 CSV 或报告需`--overwrite`；该开关优先于`--existing-file`且不受先后顺序影响。`--report`中的`config`记录本次最终归一化配置，不代表已保存到用户配置文件。

ANOVA 模型、零/负方差处理、输出报告及五软件对标口径见[ANOVA 说明](ANOVA设计与五软件对标.md)。`schema_version=1` 配置缺少字段时自动补默认值。


## AI 独立配置

AI 功能的配置位于 `%USERPROFILE%\MSA数据生成器\ai_settings.json`，与研究业务配置 `msa_generator.json` 分开保存。不要将 AI 字段直接加入现有业务 JSON，也不要作为现有 CLI 参数传入。以下说明配置契约；专项验证范围与结果另行记录，不由字段表推定功能已通过实测。

| 字段 | 默认值 / 类型 | 说明 |
| --- | --- | --- |
| `schema_version` | 整数 `1` | AI 配置格式版本，与业务配置各自管理 |
| `provider` | `deepseek` | `deepseek` 或 `openai_compatible` |
| `base_url` | `https://api.deepseek.com` | 支持 JSON 对象模式的 Chat Completions 基础地址或完整路径；远程 HTTPS，本机回环地址可使用 HTTP |
| `model` | `deepseek-flash` | 从服务返回的模型列表选择并保存的标识，不超过 200 字节 |
| `api_key_protected` | 字符串，空 | Windows DPAPI 当前用户加密后的密文，由程序生成；不接受明文 `api_key` 字段 |
| `generation_system_prompt` | 非空字符串 | AI 辅助生成系统提示词，最多 32768 字节 |
| `interpretation_system_prompt` | 非空字符串 | AI 结果解读系统提示词，最多 32768 字节 |
| `timeout_seconds` | 整数 `120` | 请求超时，10～600 秒 |

模型列表、连接测试状态和余额快照只在当前会话保留，不新增持久化字段。拉取模型、测试连接、查询余额均使用当前草稿且需手动点击；修改或保存配置不会自动联网。模型选择保存到 `model`；获取列表失败或空列表不会自动覆盖已有模型。详见[服务连接操作](结果可视化与AI助手.md)。

“选项 → AI 配置”中的“保存 AI 配置”只保存上述文件；“恢复 AI 默认”只重置内存中的 AI 设置，保存后才写入。业务配置的保存和恢复不改写 AI 文件。API Key 在界面输入、请求时使用，但保存时仅写密文；换 Windows 用户或电脑后应重新输入。切换服务类型或修改接口地址都会清空当前密钥。项目不内置可用密钥，不应将密钥写入源码、示例或提示词。

两类系统提示词可调整专业口径、评价重点和表达风格，不能修改固定回复协议。生成、追问、诊断和评价均须返回单个 JSON 对象，包含 `schema_version`、`task`、`action`、`message`、`questions`、`warnings` 及对应任务字段；禁止代码围栏和 JSON 外文字。程序附加固定协议并严格校验，不自动修复回复或降级为自由文本。配置文件版本与回复协议版本分别管理，当前均为 `1`。

启动时若识别到与旧内置默认值逐字相同的提示词，会在内存中升级到当前默认提示词；自定义内容保持原样，文件不会自动回写。需要保留升级后的默认值时，点击“保存 AI 配置”。

发送生成请求时，本机在只读上下文中增加 `generation_readiness`，说明当前配置是否满足生成前提；它不是需要用户保存的配置字段。返回的 `generate` 补丁合并后还须通过完整业务校验。指标约束全部为 `null` 或补丁为空，都不会跳过严格规格、参考尺度和其他生成要求。

图表样式、组合选择、图表导出设置和两类对话上下文暂不持久化，仅保留到程序退出。图表编辑和 AI 配置不会使已生成数据失效；AI 应用业务参数时仍遵守现有结果失效与重新生成规则。

实际使用流程、参数建议处理、数据传输范围与验证边界见[结果可视化与 AI 助手](结果可视化与AI助手.md)；完整回复字段、请求上限、错误分类与手动恢复见[AI 协议与错误恢复](AI协议与错误恢复.md)。
