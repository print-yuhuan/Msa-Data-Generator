# 结果可视化与 AI 助手

适用版本：**v1.0.0**。本文对应当前标签源码及 Windows x64 运行包。图表模型、编辑状态和图片/PDF 导出的验证范围见[图表专项验证](图表专项验证.md)，AI 验证另行记录；2026-10-30 的完整回归与修复见[审查修复记录](代码审查修复与回归.md)。

## 入口与数据来源

主导航新增“图表”和“助手”。“图表”负责图形编辑、CSV 导入和图片/PDF 导出；“助手”包含相互独立的“AI 辅助生成”“AI 结果解读”两类对话。“选项 → 助手”管理服务连接和系统提示词。

结果图表和 AI 解读共用当前选定的数据源：

| 来源 | 使用方式 | 配置与状态 |
| --- | --- | --- |
| 当前生成结果 | 先在数据页或 AI 辅助生成中获得有效结果 | 使用该结果关联的研究配置和统计指标；业务配置变化导致结果失效时不能继续作为当前数据源 |
| 导入 CSV | 先设置与文件一致的研究设计及分析方法，再点击“选择 CSV” | 支持本程序宽表/长表解析；导入时本机重新计算统计结果，不要求测量值满足生成约束 |

导入文件上限为 4 MiB，须包含与所选操作员数、部件数和重复测量次数一致的完整研究记录。长表中的 `Trial` 保留真实重复测量编号；图表使用记录对应关系，不将随机行序视为新的部件或操作员分组。

导入后的数据集保留导入时的配置快照。修改分析设置后，如需按新口径解读或绘图，应重新导入。CSV 导入不会替换数据页的生成结果；切换数据源即可选择两者。

## 七类结果图表

| 图表 | 内容 | 解释边界 |
| --- | --- | --- |
| 变异分量 | GRR、EV、AV、PV 的研究变异百分比、方差贡献率；适用时显示公差占比和过程占比 | 沿用当前分析结果的口径；标准差比例、方差比例和公差比例不可混用 |
| 测量值与部件 | 按部件显示各操作员的完整测量点及部件均值 | 点的轻微横向偏移仅用于区分重叠，不改变测量值 |
| 操作员分布 | 各操作员的箱线图与测量散点 | 四分位数采用线性插值；须线延伸至 1.5 IQR 范围内的最远观测值；不声称与所有外部软件的默认箱线定义相同 |
| 极差控制图 | 每个“操作员 × 部件”重复测量子组的极差，按操作员分面 | 所有分面共享全部子组的平均极差、纵轴和传统 D3、D4 控制限 |
| 均值控制图 | 同一子组的均值与控制限，按操作员分面 | 所有分面共享全体测量总均值，采用 A2 × 合并平均极差计算控制限；超限不直接等同于量具不合格 |
| 部件 × 操作员交互图 | 各操作员对各部件的重复测量均值连线 | 展示可能的交互形态，不替代 ANOVA 交互项显著性检验 |
| 测量值直方图 | 所有测量值的等宽分箱频数 | 不包含正态拟合、正态性检验或过程能力结论 |

各图标明分析方法、操作员/部件/重复次数和记录数；ANOVA 图另标明最终交互项处理状态及完整模型的交互项 P 值。控制图标明 CL、UCL、LCL，使用方形红点强调超限子组。极差图用于检查重复测量的一致性；均值图中较多部件均值越过重复性控制限，可能反映量具能区分部件，不应直接解释为测量系统不合格。

两种分析法的控制图均使用传统 A2/D3/D4 与合并平均极差，研究变异倍数不会替换控制图的三倍标准差原则。该明确口径不自动模拟外部软件的所有默认设置。与 Minitab、Origin、JMP、SPSS 或 MATLAB 比较时，须对齐子组定义、控制限估计方法、箱线图四分位数算法及规格参考线；尤其不能将 MATLAB 按连续记录分组的默认图与随机行序直接比较。

### 基础编辑

在“图表”选择图表类型，点击“编辑图表”，可调整当前图表的标题、横纵轴名称、主色、线宽、点大小、纵轴上下限，以及网格、图例和控制限/规格参考线。“收起编辑”仅隐藏编辑器，不丢弃草稿。修改先保留为该图的独立草稿，点击“应用编辑”后更新预览和导出；切换图表保留草稿。“撤销草稿”恢复上次有效设置，“重置当前图表”恢复当前图的默认外观，“重置全部图表”恢复七图外观并保留组合选择。

编辑器按“标题与坐标、图形外观、图例与参考线”分组。线宽和数据点大小直接选择；网格、图例及参考线使用复选框。短选项在窄窗口自动换行，统计数据点本身不使用动画。

纵轴留空使用自动范围；填写时必须为有限数值，下限必须小于上限。半输入内容或无效范围不会破坏已应用的图形。应用失败时保留草稿并说明原因；修正后再次应用，或撤销草稿。底栏在有草稿时提供“应用编辑”快捷操作。导出前须先应用或撤销所有待导出图表的草稿，避免把未生效的编辑误当成导出结果。

图表编辑只影响显示和导出，不修改测量数据、统计结果或生成约束。不同图表分别保留编辑值。样式、组合勾选和图表导出设置仅保留在当前程序会话，暂未写入业务配置文件。

当大数据中心与微小变异同时出现时，坐标轴可显示明确的数值偏移说明。缩窄纵轴范围会裁剪图形，不把超出范围的数据强制贴到边界上。

## 图片与 PDF 导出

在“图表导出”选择格式、范围和分辨率，然后使用底栏导出操作。

格式与输出范围直接显示为选择按钮；组合中的图表使用复选框，可全选或清空。文件名及目录与图形选择分组，避免把样式调整与文件保存混在一起。

| 设置 | 选项与行为 |
| --- | --- |
| 格式 | PNG、JPEG、PDF |
| 范围 | 当前单图，或勾选图表组合 |
| 组合布局 | 单列纵向组合或两列组合；按图表清单顺序排列，未勾选图表不导出 |
| 单图分辨率 | 1200、1800 或 2400 像素宽；保持比例缩放，不拉伸图形 |
| 文件名 | 填写不含路径和扩展名的名称，程序按格式补充扩展名 |
| 目录 | 留空或相对路径以默认用户配置目录为基准，可使用“选择目录” |
| 同名文件 | 自动追加 `_1`、`_2` 等序号，不覆盖已有文件；与 CSV 的同名策略独立 |

多图组合生成一张图片或**单页 PDF**。PDF 内部使用高分辨率图像，包含与图形一起绘制的中文文字；它不是可直接编辑图元、选择或检索文本、无限放大不失真的矢量 PDF。页面尺寸由组合画布和分辨率计算，不固定为 A4；文件只包含所选图表，不附带完整统计报告或 AI 对话。若用于打印，建议选择较高分辨率并结合最终版面检查字号。

组合支持全选、清空和已选数量提示；零张时禁用导出。导出在后台进行，使用开始导出时的数据与已应用样式快照。同名文件自动追加序号，失败时不损坏既有文件。成功信息只在底部状态栏显示；“上次导出目录”始终占位，首次成功前禁用，完成后不改变输出区域布局。错误在页内说明原因和恢复操作，细节同步进入日志，不弹全局通知。

预览生成失败时可重试渲染、重置当前图表或切换数据源；相同错误不在每帧重复刷日志。文件名、目录、图元、画布规模和输出参数在编码前校验；写入或编码失败可修正设置后重试。导入失败保留原有数据。底栏位置固定，页内错误说明随正文滚动。

## 配置 AI 服务

1. 打开“选项 → 助手”，选择“DeepSeek 预设”或“自定义 OpenAI 兼容接口”。
2. 填写接口地址和 API Key，点击“拉取模型列表”，从“选择模型”下拉框中选择模型，无需手工输入名称。长列表支持滚动及方向键选择。
3. 点击“测试连接”，确认所选模型可以完成 JSON 模式请求。DeepSeek 官方接口还可点击“查询 DeepSeek 余额”。按需要修改超时与两类系统提示词。
4. 点击“保存 AI 配置”，供下次启动加载；修改未保存配置也可用于当前会话的请求。
5. 打开“助手”，输入需求后点击“发送”。仅修改或保存配置不会自动发起请求。

AI 配置分为服务连接、高级参数和系统提示词。请求超时提供常用秒数快捷选项，也可输入自定义值；提示词通过“辅助生成 / 结果解读”切换编辑，切换不会丢弃另一类草稿。

| 项目 | 默认值或规则 |
| --- | --- |
| DeepSeek 预设 | 地址 `https://api.deepseek.com`，初始模型 `deepseek-flash`；可拉取实时列表后选择其他模型 |
| 自定义服务 | 使用支持 JSON 对象模式的 OpenAI 兼容 Chat Completions 接口；支持服务根路径、`/v1` 等基础路径或完整 `/chat/completions` 路径 |
| 传输 | 远程服务要求 HTTPS；HTTP 仅允许 localhost/回环地址的本机服务 |
| API Key | 远程请求需要填写；本机服务可按服务要求留空。切换服务类型或修改接口地址都会清空密钥，避免误用 |
| 请求超时 | 10～600 秒，默认 120 秒 |
| 回复形式 | 生成、诊断、追问及评价均为严格 JSON；非流式完成并经本机校验后展示，禁止代码围栏与 JSON 外文字 |
| 请求恢复 | 显示错误代码、说明与恢复建议；服务异常、取消或超时不会自动反复请求 |

模型列表来自配置地址的 `GET /models`，兼容 `/v1` 或完整 `/chat/completions` 地址。列表只在本次程序会话内缓存，所选模型随 AI 配置保存。刷新失败或返回空列表时保留原选择；已保存但未出现在当前列表中的模型标注为“当前配置，未验证”。切换服务、修改地址或密钥后，旧列表和测试状态作废，避免混用不同账户的结果。新配置没有模型时，应先成功拉取再选择；不支持模型列表的服务会给出明确错误，不凭空编造模型名称。

“测试连接”实际向所选模型发送一条简短测试消息，验证 Chat Completions 与 JSON 对象模式，可能产生少量费用。测试不发送研究数据、对话历史或自定义系统提示词。拉取模型成功只表示列表接口可访问；余额查询成功只表示取得账户余额快照，均不等于模型调用成功。连接测试通过也不代替业务参数校验或实际生成测试。

余额查询使用 DeepSeek 官方 `GET /user/balance`，显示币种、可用余额、赠金及充值余额；自定义服务不使用此专用接口。三类请求统一支持超时和取消，执行时锁定连接字段以避免误用配置，结果在固定区域显示，底部状态栏提供简短提示，不弹窗、不自动保存。失败后按错误说明修正配置再手动重试。

接口依据：[DeepSeek 模型列表](https://api-docs.deepseek.com/zh-cn/api/list-models/)、[DeepSeek 余额查询](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/)。

DeepSeek 预设依据[官方首次调用说明](https://api-docs.deepseek.com/zh-cn/)，具体可用模型和账户权限以服务商为准。自定义接口需要支持兼容消息结构与响应格式，不能仅凭接口名称断言兼容全部服务商。

### 系统提示词与密钥保存

“AI 辅助生成”和“AI 结果解读”的系统提示词分别编辑，可调整角色、专业口径、评价重点和表达风格。两类回复的字段结构由程序协议固定，提示词不能要求修改字段、输出代码围栏或在 JSON 外追加文字。“仅恢复默认提示词”保留连接配置；“恢复 AI 默认”恢复整套 AI 设置并清空当前密钥，均需保存后才写入文件。

AI 配置独立保存在 `%USERPROFILE%\MSA数据生成器\ai_settings.json`。API Key 通过 Windows DPAPI 按当前用户加密为 `api_key_protected`，不以明文写入业务 JSON、报告或日志。该密文通常不能直接迁移给另一 Windows 用户或另一台电脑；迁移后应重新输入密钥。两类系统提示词和连接参数按普通配置保存，请勿把密钥写入提示词或对话文本。

## AI 辅助生成

空会话提供常用需求示例。点击只会填入输入框；已有文字时追加示例，仍由用户修改、确认并发送。对话分别标明用户、AI 与本机执行消息，输入区显示字符数和状态说明，反馈变化不会移动输入框。

示例需求：

> 3 名操作员、10 个部件，每件重复测量 3 次。规格 9～11，采用 ANOVA；GRR/TV 不高于 20%，P/T 不高于 20%，ndc 至少 5，保留 4 位小数。

处理过程为：AI 理解当前配置与上下文 → 返回结构化说明和业务参数建议 → 本机校验协议及参数 → 调用现有生成器搜索数据 → 本机核对指标。模型不会直接写入其编造的测量值，也不会执行其返回的代码。缺少字段、类型错误、重复键、代码围栏或 JSON 外文字都会使本轮回复被拒绝，程序不自动截取或修复。

请求会附带本机生成前置检查结果，帮助模型识别缺少的规格、波动尺度或约束冲突。即使所有指标均“不约束”，严格规格和尺度要求仍须满足；空参数补丁也不能绕过这些条件。模型建议先合并到当前配置，通过完整可执行性校验后才会应用并启动生成。

正常生成回复中的有效参数会应用到当前研究并启动本机生成。缺少关键信息时，AI 可先追问；不符合参数范围或缺少必要条件的建议不会应用，原配置和结果保留供修正。参数可执行但本机搜索失败时，程序保留实际原因，再请求 AI 解释与建议。诊断建议**不会自动循环重试**：可继续发送要求，或点击“按建议重试”。若等待回复期间研究参数已改变，返回的过期参数会被丢弃，不保留为可直接应用的建议；需要基于当前配置重新发送需求。已保存的建议在研究参数后来改变时也会作废。

例如，可继续输入“保留规格和 P/T 上限，只将 GRR/TV 上限调整到 25%”，使 AI 基于同一会话重新提出参数。未明确要求修改的参数应保留；实际建议内容会显示在对话中。生成仍受本程序支持的研究设计、数值范围、精度和搜索能力约束，有限搜索失败不等于数学上已证明无解。

生成成功的状态与指标以本机结果为准。AI 只能调整研究设计、分析、规格、生成和指标约束，不能修改 CSV 输出路径、文件名、AI 接口或密钥。

## AI 结果解读

先在图表页选择当前生成结果或导入 CSV，再切换“助手 → AI 结果解读”。例如：

> 请解释该研究的重复性、再现性和部件区分能力，说明 GRR/TV、P/T 与 ndc 的含义，以及优先改进方向。

发送时会把所选数据集的测量矩阵、研究配置、计算指标和约束检查提交至已配置的 AI 服务。CSV 输出路径不作为分析上下文发送。评价以固定 JSON 字段组织总体结论、指标评价和改善建议；本机按指标键附加真实数值，不接受模型另填数值替代统计结果。可以继续追问指标差异、交互作用、置信区间或改善建议；本机计算结果保持不变。

如果数据集或分析配置改变，须“新建会话”后再解读，以免混用两个研究的结果。请求发出后才切换数据源时，返回内容会标明仅针对发送时的旧快照。AI 评价是辅助文字解释，不替代本机计算、专业判断或真实测量；尤其不能依据模拟数据断言现场测量系统合格。

## 会话与异常处理

- 两类对话分别保存上下文，只在当前程序会话中保留。关闭程序后清除；需要留存时使用“复制对话”。
- 对话达到条数或长度上限时会明确提示新建会话，不在后台悄悄丢弃早期上下文。
- 历史中只向模型回传已校验的结构化助手回复；本机状态单独提供，错误和无效回复不冒充有效模型历史。
- “取消”作用于当前 AI 请求或本机生成任务。取消不会自动重试，也不自动保存配置。
- 请求失败时显示错误代码、中文说明与恢复建议。“重试本轮”重发 AI 请求，“按建议重试”才会把已确认的诊断参数交给本机生成器。
- 接口返回鉴权、余额/权限、限流或服务错误时，检查对应配置或账户后再手动发送；不要通过增大搜索预算处理接口错误。接口不支持 JSON 模式时不会自动降级成自由文本。
- 编辑图表与 AI 配置不会使业务结果失效；AI 应用研究参数后按正常业务规则更新结果状态。

完整字段约定、上下文上限、取消边界与恢复步骤见[AI 协议与错误恢复](AI协议与错误恢复.md)。小模型和大模型使用相同本机校验，具体模型的多轮可靠性须分别实测。

## CLI 范围

当前新增图表编辑、图表导出和 AI 请求均由 GUI 操作，暂未提供相应 CLI 参数。CLI 继续支持研究、生成、分析、CSV 导出及 JSON 报告；可以将其导出的 CSV 导入图表页使用。AI 连接与密钥配置独立于业务 JSON，不通过现有业务参数覆盖。

图表的自动化、实际文件回读与视觉检查分别记录在[图表专项验证](图表专项验证.md)。五软件风格参考不等同于所有参数、所有图形和所有系统环境逐像素一致；图元直接拖拽编辑、任意图表类型、矢量 PDF、分页报告和交互式数据点提示不属于当前基础编辑范围。

实际模型用例、问题发现与修正后的验证范围见[AI 专项验证](AI专项验证.md)。已有统计内核和外部软件验证记录继续按原构建范围阅读；图表通过项以图表专项和当前回归的实际执行结果为准。版本号保持 v1.0.0，Release 仅提供 Windows x64 便携运行包，源码从仓库标签获取。
