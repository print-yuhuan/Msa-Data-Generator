# 界面设计规范

本规范约束 v1.0.0 当前源码的七个页面、公共控件及状态流转，用于后续修改和验收。这里描述设计要求，不替代实际测试记录；已验证范围和待验收项目见[界面验收](界面验收.md)。统计公式、生成算法、CSV 字段及配置含义以[使用说明](使用说明.md)和[配置参考](配置参考.md)为准。

“结果图表”“AI 助手”及“AI 配置”已纳入 v1.0.0 当前发布；图表与 AI 的实际覆盖范围分别见专项验证。本页描述设计要求，不用设计规范代替验收证据。

## 页面与信息分组

| 页面 | 信息顺序与分组 | 主要操作及反馈 |
|---|---|---|
| 数据 | 研究摘要；生成设置、指标约束；结果摘要；指标复核、数据预览、分析详情 | 研究设置入口跳转到“选项 → 研究”；生成、取消和导出位于固定底栏；无结果、生成中、结果有效和需要重新生成分别表达 |
| 图表 | 数据源、图表类型、预览、当前图表编辑器、组合与导出设置 | 当前结果或 CSV 导入；图表编辑不修改统计数据；单图/组合导出使用快照，完成仅底栏提示 |
| 助手 | 辅助生成/结果解读模式、数据上下文说明、多轮消息、输入区 | 发送、取消、新建会话、复制对话；生成失败展示原因，建议须用户重试；解读数据变更要求新会话 |
| 日志 | 当前记录数及信息/警告/错误概览；筛选与跟随操作；按时间排列的记录 | “全部、警告、错误”筛选；复制当前显示记录；滚动离开底部暂停跟随，回到底部恢复跟随；空列表显示对应空状态 |
| 选项 | “研究”：研究设计、规格与尺度、数值精度与允许误差、数据随机性与搜索；“分析”：分析方法、统计选项、分析口径与过程参数；“导出”：CSV 文件导出、运行顺序、配置文件位置；“助手”：服务连接、密钥、超时和两类系统提示词 | 设置值与说明就近排列；保存、恢复默认置于底栏；格式说明随选择更新，依赖条件不满足时禁用并说明原因 |
| 帮助 | 快速入门、分析指标、导出顺序、文件变量、命令说明、图表助手 | 分类切换后从该主题顶部阅读；变量名可点击复制；变量命名规则只在本页说明，时间戳列在毫秒之后 |
| 关于 | 应用图标与名称；版本及许可标签；产品用途；作者、原仓库及项目许可；组件许可和运行环境 | 复制版本信息、打开作者/仓库、打开许可目录；作者及原仓库地址显著可见；不展示尚未实现的更新功能入口 |

帮助内容应同时解释 Xbar-R 与 ANOVA。关于页展示 MIT 许可、作者与项目来源，并保留完整许可的获取入口；不把已移除的输入法测试或大段许可声明重新放回帮助页。

## 视觉与尺寸

尺寸均为逻辑像素，实际像素由 DPI 和界面缩放决定。优先使用现有公共控件与颜色令牌，不为单个页面另建一套样式。

| 项目 | 约定 |
|---|---|
| 色彩 | 主文字 `#20334B`，次要文字 `#64748B`，主要操作/选中 `#3B65E8`，成功 `#16866B`，页面背景 `#F3F5FA`，卡片白色，分隔线 `#DFE6F0`；控件浅底 `#F6F8FD`、悬停浅底 `#EDF2FC` |
| 状态表达 | 成功、警告、错误同时使用文字标签，不单靠颜色传达；禁用态仍应可读，并在相邻位置解释启用条件 |
| 字体 | 使用程序现有中文字体链；页面标题、卡片标题、正文、辅助说明保持固定层级，正文通常使用现有 18～20 字号档位；数值与单位相邻，辅助说明不得比输入值更抢眼 |
| 尺寸基线 | 常规输入框、下拉框、按钮、分段选择器与页签高 40；状态徽标高 28；紧凑行内操作可用 32～36，但同一行对齐 |
| 间距 | 页面左右留白 16 或 24；卡片内边距 16～20；相关控件间距 8～12；卡片间距 12～16；双栏间距 16～20；使用少量固定档位，避免零散像素值 |
| 边界 | 卡片圆角 14、轻边框和弱阴影；控件圆角约 9～10；焦点边框清晰，不与普通悬停混淆 |
| 底栏 | 高度固定为 64；状态文本使用固定单行空间，过长时裁切，不撑高底栏、不挤动按钮；长错误细节在日志中查看 |

表格统一对齐表头、数值和单位。测量值按配置小数位展示；百分比、方差分量和统计量按各自含义标注，不能为缩短文案而改变计量口径。

## 窗口与响应式

- 默认客户区目标为 1280 × 820，首次显示前在主屏工作区居中；结合 DPI、界面缩放、窗口边框和任务栏约束尺寸。常规最小客户区为 620 × 500；工作区不足时允许继续适配，不承诺极小工作区仍能一次展示全部内容。
- 页眉高 64，主导航区高 48，底栏高 64；正文独立滚动。滚动区域预留滚动条宽度，避免内容增减时整页左右跳动。
- 断点按滚动区扣除留白和滚动条后的**可用内容宽度**判断：数据页小于 1080 改为单栏，选项页小于 1100 改为单栏；单栏保持先设置、后结果的阅读顺序。
- 帮助分类在可用宽度小于 700 时使用下拉框，其余情况下使用页签。说明、仓库地址等长文本允许换行；控件不得越出容器。
- 连续拖动窗口边缘时同步布局和绘制。新增区域不得依赖松开鼠标后才刷新；窗口尺寸变化不触发正文位移、缩放或模糊动画。

## 状态与导航

| 场景 | 必须保持的行为 |
|---|---|
| 首次进入 | 无结果时显示占位或说明，禁止导出；不以零值冒充计算结果 |
| 开始生成 | 输入区进入忙碌态；底栏原位显示取消操作及进度；已有结果可保留供查看，但任务运行中不可导出 |
| 取消或失败 | 若已有结果对应当前未变更的业务配置，结束任务后恢复该结果的可用状态；没有有效旧结果时保持不可导出；失败原因进入日志 |
| 修改参数 | 研究、生成或分析参数实质变化后标记结果失效；同值选择不清空结果、不重置滚动位置，也不重复触发状态变更 |
| 修改导出 | 目录、模板、格式、同名策略及运行顺序变更不使已有数据失效；下次导出使用当前配置 |
| 使用示例 | 载入示例研究与生成参数，其余分析选项恢复示例默认；保留当前分析方法、交互项模式及显著性水平，并保留全部导出设置，避免意外改动输出目的地和文件处理方式 |
| 导航 | 页面或分类切换关闭浮层菜单；当前项与键盘焦点各自可辨认；方向键导航和 Enter/空格激活与鼠标操作保持一致，焦点不遗留在已隐藏页面 |
| 短反馈 | 保存、复制、导出等操作只在固定底栏显示简短反馈；提示到期或离开所属页面后清除，不把上页成功消息带到下一页；按钮宽度和页面布局不因“已复制”等文字改变 |
| 日志与链接 | 复制日志仅覆盖当前筛选记录，空列表禁用复制；目录不存在时不提供无效打开操作；打开外部链接后的底栏提示只表示已交给系统处理 |

保存配置与修改当前会话参数是不同操作，应明确说明保存后才会写入配置文件。恢复默认、取消生成及失败恢复均不得悄悄覆盖个人配置文件。

## 新增页面的状态规则

- 结果图表以当前有效研究或独立导入快照为数据来源。图表样式与导出范围不改动测量值；CSV 导入后修改分析口径应重新导入。
- 图表预览与编辑器在宽窗口并排、窄窗口上下排列；组合勾选、导出文件名及目录与图表编辑分组，避免将 CSV 输出策略混用到图表导出。
- 图表预览高度随窗口可用高度适配，不因全宽布局无限增高；图内已有标题时不再重复显示卡片标题。顶部数据源、图种和编辑入口在宽窗口合并为一行。
- AI 辅助生成与结果解读分别保留对话，明确当前任务是在等待服务回复还是执行本机搜索。忙碌时允许取消，禁止重复发送及清空正在使用的会话。
- AI 生成、诊断、追问和评价使用固定 JSON 协议，本机校验后再整理为可读内容；无效回复不修复、不加入有效历史、不应用参数。失败诊断不自动循环生成，保留“按建议重试”或继续输入的入口。
- AI 解读显示实际数据源，并在发送前说明测量数据和统计结果将提交至已配置服务；数据源或分析配置变更后要求新建解读会话。
- AI 配置有独立的保存与恢复默认操作。切换服务或修改接口地址清空密钥；显示密钥为显式开关，日志与普通配置不记录明文密钥。
- AI 配置宽屏按连接/高级参数与系统提示词分列，窄屏串排；两类提示词切换保留草稿，首次载入从开头阅读。空会话示例只填入或追加到输入框，不直接发送；角色卡片区分用户、AI 回复和本机执行。
- AI 请求失败展示错误代码、说明和恢复建议，提供手动“重试本轮”；区分重新请求 AI 与应用诊断建议后执行本机生成。研究配置变化后使旧请求和建议失效，取消不触发自动重试。
- 图表编辑值和对话在当前会话内保留；不将会话状态误标为已持久化设置。

## 动效与可操作性

- 状态色、边框、页签指示条、开关和进度反馈使用约 120～180 毫秒的局部过渡；只对确有连续变化意义的属性补间。
- 短且互斥的选项使用可换行的选择按钮，当前项、焦点与禁用态分别表达；方向键及 Home/End 切换，Tab 只进入当前项。长列表继续使用下拉框。
- 包含内容、参考线与组合图选择使用复选框；开关用于立即启停的功能。展开高级内容使用明确的展开/收起按钮，不以开关冒充配置项。
- 正文、表格及输入文字不做缩放或位置补间；生成、日志追加和提示更新不触发整页淡入、闪动或重新排版。
- 页面切换保持正文完全不透明，预览与导出状态说明固定占位；搜索预算只进行局部展开，隐藏及展开过程中的输入框不能取得焦点。
- 尊重 Windows 的界面动画偏好。系统减少或关闭动画时缩减非必要过渡；内容与状态切换仍及时完成。
- 保留 Tab/Shift+Tab、Enter/空格、页签方向键和标准文本编辑快捷键；禁用控件不响应修改。下拉框的展开方向与滚动区域不得遮挡主要操作。
- 页面提示只说明用户可采取的动作；详细诊断放入运行日志，不以全局右下角弹窗打断操作。

## 术语与文案

| 使用词语 | 说明 |
|---|---|
| 交叉量具 R&R；Xbar-R（均值极差法）；ANOVA（方差分析法） | 分析对象与方法的统一写法 |
| 操作员、部件、重复测量次数 | 用于研究设计；避免在相同含义下混用人员、产品件数、轮数等名称 |
| 数据生成种子、运行顺序种子 | 分别控制生成数据与记录排列，不能都简称为“随机种子”而不提供上下文 |
| 规格下限、规格上限、容差宽度、研究变异倍数 | 不将规格限称为控制限，不将容差宽度与单侧规格口径混为一谈 |
| 重复性、再现性、总量具 R&R、部件间变异、总变异 | 结果和分析说明采用一致名称，并保留 EV、AV、GRR、PV、TV 的对应关系 |
| 标准差占比、方差贡献率、P/T、可区分类别数 ndc | 各指标按自身定义解释；满足生成约束不等同于测量系统合格 |
| Trial、StdOrder | CSV 字段原样保留；分别说明为真实重复测量编号和标准运行序号，不能因导出排序重新编号 |

操作名使用“保存配置、恢复默认、生成数据、重新生成、取消生成、导出 CSV、复制日志”等直接动词。成功反馈尽量一句话完成；错误文案说明原因或下一步，不暴露无助于操作的实现细节。文件名变量及 CLI 参数保留已有标识符，不因界面术语润色改名。

## 统计图表

- 绘图区采用白底、低对比网格和清晰轴线；标题、方法/研究设计、图例、坐标与说明分层排布。数据线保持清晰，不对统计数据点做位移或插值动画。
- 控制图按操作员分面并共享纵轴、总中心与控制限。中心线为绿色，控制限为红色虚线，超限值增加方形标记；规格参考线用琥珀色并标记 LSL/USL，避免混淆。
- 点颜色与图例统一。部件和操作员分布另用菱形表示均值；箱内中位数与均值标记保持区分。分箱由实际样本范围决定，规格线只影响显示范围。
- 图表编辑采用独立草稿，应用成功后才改变预览与导出；失败保留已应用状态。切图不串用输入框缓冲，撤销和重置同步恢复控件文字。
- 预览按数据快照、已应用外观和尺寸缓存；错误也缓存，避免逐帧失败和日志刷屏。数据源、图种、尺寸或外观改变时重新生成场景。
- 导出使用不可变快照，后台编码不锁住正文。空组合禁用导出，尚未应用的相关草稿须先处理。同名文件追加序号；编码或写入失败保留原文件并给出恢复操作。

图表模型与编辑功能的实测范围见[图表专项验证](图表专项验证.md)。这些规范不表示所有外部软件的默认图形或统计估计口径完全一致。
