## 启动与工作流程

从 [v1.0.0 Release](https://github.com/print-yuhuan/Msa-Data-Generator/releases/tag/v1.0.0) 下载 `MSA_Data_Generator_v1.0.0_Windows_x64.zip`，解压后双击 `msa_generator.exe`。运行包无需安装向导。中文字体、应用图标及窗口清单均已内嵌，主程序可单独复制到空目录运行，不依赖外部 resources 或字体文件；运行时无需 Python、Excel 或 Minitab，显卡仍需支持 OpenGL 3.3 Core。运行包包含 `LICENSE`、`NOTICE`、`licenses/` 及第三方声明；再分发时按 MIT 和各第三方许可保留适用通知。`msa_cli.exe`是命令行工具；`msa_tests.exe`用于发布验证；`msa_export_tests.exe`用于导出回归和同组实测入口，界面、渲染及内嵌资源测试程序按需构建。CLI、测试程序、文档及示例都不是 GUI 运行依赖，测试工具用途见[项目 README](../README.md)。

字体按完整原始内容进行无损分块压缩，首次使用时在内存中解码并复用，不会仅保留静态界面用字，也不会向临时目录写入字体。原字体已有的字符覆盖、布局及 hinting 信息保持不变，文件名、路径和其他动态中文文本沿用相同字体支持。程序增加共享字体所有权、按需回退和 256 条文本度量缓存；体积和实际性能测量见[字体优化与性能验证](字体优化与性能验证.md)。

默认窗口客户区以 **1280 × 820 逻辑像素**为目标，按 Windows DPI 和界面缩放换算，并依据主屏可用工作区缩小，首次显示时居中且避开任务栏。逻辑尺寸不包含标题栏和边框，因此实际屏幕像素尺寸会随显示缩放变化。常规最小客户区为 620 × 500 逻辑像素；可用工作区更小时进一步适配，较长内容通过页面滚动访问。

1. 在“选项 → 研究”设置操作员数、重复测量次数、部件数、规格与尺度、数值精度及允许误差。
2. 在“选项 → 分析”选择均值极差法或方差分析法，按研究需要配置交互项、历史过程参数和统计选项。
3. 在“数据生成”设置数据中心、生成优先级和五项指标约束。数据中心可留空；“不约束”对应 JSON `null`。
4. 点击“生成数据”，查看“指标复核”“数据预览”和分析详情。搜索在后台运行，可在任意页面取消。
5. 在“选项 → 导出”选择 CSV 格式、目录、文件名模板与同名文件处理方式；长表可另设运行顺序。点击“导出 CSV”后直接保存，模板中的研究参数与指标取自已生成结果。

## 界面操作

- 当前源码的主导航按“数据、图表、助手、日志、选项、帮助、关于”排列。导航与结果查看使用页签，生成优先级、操作员数和重复测量次数使用分段选择器；点击即可切换。
- “规格内生成”开关开启时遵守规格限，关闭时允许超出规格限。部件数和小数位数使用步进器，分别限制在 5～10 和 0～10；运行顺序使用单选按钮，附加选项使用复选框。
- 宽窗口下，数据生成页并排显示约束与结果；选项按分类显示相关设置，宽窗口采用两栏，窄窗口改为单栏。内容区独立滚动，底部操作区固定。
- 拖动窗口边缘或四角时，按当前客户区尺寸实时重排并绘制新增区域。滚动和重排时正文不使用位置、缩放过渡，避免文字因运动插值而变模糊。
- 复核区突出显示 GRR/TV%、P/T% 和 ndc，并用状态标记区分满足、未约束和异常。“分析详情”展示 Xbar-R 的计算口径与分量；选择 ANOVA 时页签为“ANOVA 详情”。
- 搜索进度条表示已用候选次数预算，不代表找到解的概率或完成百分比。生成过程中参数暂不可编辑，生成按钮变为“取消生成”；重新生成时保留上次结果并标记“更新中”，导出暂不可用。完成后原位更新数据，保留当前结果页签和滚动位置。
- 同一配置下重新生成被取消或失败时，仍可查看并导出“上次成功结果”；业务参数已修改的旧结果不会恢复。选择当前已有值不会使结果失效；修正输入后清除旧错误提示，重新生成时再次校验。
- “载入示例”保留当前分析方法、交互项模式与显著性水平，以及全部导出偏好；其他研究、生成和分析参数恢复示例值。“恢复默认”则重置所有业务配置，两者均不会自动保存文件。
- 保存配置、导出 CSV、复制等操作完成后，仅在固定底部状态栏显示“配置已保存”“CSV 已导出”等简短提示，不改变页面布局。详细信息保存在“运行日志”，表单错误在相关页面显示。
- 底栏短提示显示约 6 秒，离开所属页面后清除；生成进度优先。选项页标明是否存在未保存更改。日志支持“全部、警告、错误”筛选，复制仅包含当前显示记录，空列表时禁用复制。
- Tab / Shift+Tab 移动焦点，Enter 或空格激活按钮和开关；页签、分段选择器支持方向键，步进器支持方向键。输入框和下拉菜单保留键盘操作与中文输入。
- EUI-NEO 页签指示器、分段选项、开关、进度条和控件状态使用约 120～180 毫秒的短过渡；搜索预算采用局部展开。程序启动时读取 Windows 界面动画设置，关闭系统动画时减少过渡。

选项按操作目的分为四类，避免在一页内混排所有参数：

| 分类 | 内容 |
|---|---|
| 研究设置 | 研究设计、规格与尺度、数值精度与允许误差、随机性与搜索 |
| 分析选项 | 分析方法、分析口径与过程参数、统计选项；ANOVA 专用设置仅在相应方法下提供 |
| 导出设置 | CSV 格式、目录与文件名、同名处理、运行顺序、配置文件位置 |
| AI 配置 | 服务类型、接口地址、模型列表选择、密钥、连接测试、DeepSeek 余额查询、超时与两类系统提示词；独立保存，不写入研究业务配置 |

帮助页提供“快速入门、分析指标、导出顺序、文件变量、命令说明、图表助手”六个分类。文件名变量表和命名示例集中在“文件变量”，点击变量名复制包含方括号的名称；选项页只保留文件名输入及导出设置。

## 参数与约束

- 研究设计支持 2 或 3 名操作员、每个部件重复测量 2 或 3 次、5～10 个部件，共 24 种组合。
- 目标支持不约束、目标值、区间、不高于、不低于。目标值允许误差留空时用默认误差，填 0 表示零误差；其他模式不额外加目标误差。
- EV/TV%、AV/TV%、GRR/TV%、P/T%目标误差单位为“百分点”，ndc 目标误差为整数。
- 严格模式至少需要一个规格限，输出不超规格；宽松模式允许超规格。
- P/T 约束需要规格限或独立分析容差，支持单侧规格。缺少双侧规格或显式选参考尺度时，填写参考 TV_SD 或历史标准差。
- 有限搜索失败不代表已证明无解。精度不足、共同约束冲突和搜索预算耗尽分别处理。

EV、AV、GRR、PV、TV 均为标准差（1σ）。EV/TV%、AV/TV%、GRR/TV% 为 100 × 对应标准差 / TV_SD。双侧规格且未设置独立分析容差时，P/T = 100 × 研究变异倍数 × GRR_SD / (USL−LSL)；单侧规格和独立分析容差的口径见[配置参考](配置参考.md)。研究变异倍数默认 6。ndc=max(1,floor(1.41×PV_SD/GRR_SD))；GRR 为零时不可计算。复核百分比显示两位小数，ndc 为整数；实际判断使用完整精度。满足生成约束不等于测量系统合格。

## 配置与静默保存

正式配置为 schema_version=1。默认位置是 `%USERPROFILE%\MSA数据生成器\msa_generator.json`；启动自动读取已有文件，不自动覆盖。

“保存配置”直接写入默认位置，无文件弹窗。修改研究、生成或指标约束参数后必须重新生成；仅修改导出目录、文件名模板、同名策略、CSV 格式或运行顺序不使已有数据失效，也不重置预览和复核页。输出目录留空使用默认配置目录，相对目录也以该目录为基准；目录不存在时创建。默认追加序号，选择“覆盖文件”后才原子覆盖。底部状态栏显示短提示，日志记录实际导出路径。生成参数和计算口径始终使用结果关联的配置，导出设置独立取当前值。

默认 CSV 为带部件列号和操作员标记的宽表，参考 `默认.csv`：左上角留空，首行为从 1 开始的部件编号，首列为 A、B、C 等操作员标记；每名操作员连续占用“重复测量次数”行。数据按操作员 → 重复测量编号排列，总大小为“操作员数 × 重复测量次数 + 1”行、“部件数 + 1”列。保留指定小数位，使用 UTF-8 BOM、英文逗号、CRLF，小数点固定为“.”。

## CSV 导出格式与运行顺序

“选项 → 导出 → CSV 导出格式”支持默认、Minitab、SPSS、JMP 19、Origin、MATLAB。默认使用上述带列号和操作员标记的宽表；五种软件共用四列长表`Operator,Part,Trial,Measurement`，每行一次测量，UTF-8 无 BOM、英文逗号、CRLF，小数位取生成数据的配置。Operator 使用 A、B、C；Part 和 Trial 从 1 开始。格式说明随选择更新，所有 CSV 导出入口均使用配置，不弹额外选择窗口。

JMP 导入长表后，先核对列的建模类型：Operator 和 Part 用“名义”，Measurement 用“连续”。直接点击数据表左侧列列表中 Part 名称前的小图标，在菜单中选择“名义型”；图标由蓝色三角形变为红色条形即表示设置成功。Part 的数据类型保留“数值”，不需要修改数据值或另加列属性。CSV 本身不能存储这一 JMP 建模类型，JMP 可能自动把数字 Part 识别为连续列；此时量具随机效应分析会提示“随机效应不支持连续部分列”。在“变异性/计数量具图”中，将 Measurement 指定为 Y 响应、Operator 指定为 X 分组、Part 指定为部件/样本 ID，选择交叉模型；Trial、StdOrder 不加入随机效应模型。

运行顺序区的规则为：

- 不随机化：标准序 `Trial → Part → Operator`。
- 随机化所有运行顺序：打乱全部完整测量记录，允许人员、部件、Trial 跨组混排。
- 在操作员内部随机化：逐 Trial、逐操作员安排，每个 Trial＋Operator 内独立打乱部件顺序。“随机化操作员顺序”仅此模式可用，每项研究只确定一次人员顺序，各 Trial 沿用。
- 随机数种子允许留空，填写时必须为 1～9223372036854775807 的整数。使用独立随机数生成器，不影响数据生成算法；固定种子可复现同一排列，不要求与 Minitab 同种子逐项相同。留空时为本研究选择一次种子，研究结果的复制和五种软件导出均复用它。
- 勾选“在导出文件中存储标准运行顺序”时，在首列增加`StdOrder`，记录随机化前完整的 1～N 标准序号。CSV 行序就是实际运行顺序；Trial 不重新编号。记录不丢失、不重复，测量值、对应关系及所选 Xbar-R/ANOVA 统计结果保持不变。
- 默认宽表不能完整表达逐条测量的随机顺序，因此运行顺序选项禁用且不参与导出。切回长表时保留已设的运行选项。

CSV 格式使用 `output.format`（`default/minitab/spss/jmp19/origin/matlab`）和`output.run_order`（`mode`为`standard/all/within_operator`，另含`randomize_operators`、`seed`、`store_standard_order`）。缺失字段自动补默认值；保存、启动加载、恢复默认均包含这些字段。默认格式为`default`、不随机化、种子空、两个复选框关闭。格式与运行顺序只作用于导出；目录、命名模板及追加序号/覆盖机制独立配置。

StdOrder 公式为`((Trial−1)×部件数+Part−1)×操作员数+操作员编号`，A=1、B=2、C=3。Trial 始终是原重复测量编号，不是随机化后的行号。两个种子互相独立：“研究 → 随机性与搜索”的数据生成随机种子控制测量值，“导出 → 运行顺序”的种子控制导出行序。GUI 同一组数据比较三种顺序时直接重复导出；若重新生成且生成种子为空，统计值可能变化。跨 CLI 进程复现随机长表应同时固定两个种子。

已有同组实测：只生成一次 90 条测量，三种顺序的 Trial、StdOrder、值和 21 项统计均通过 Minitab 22.6 核对；见[专项报告](2026-10-25_同组数据三种运行顺序Minitab对标.md)。在 Minitab 选择交叉量具 R&R 的 Xbar-R 方法，保持研究倍数和规格一致，比较%Study Var 及总量具 R&R 的%Tolerance；操作步骤见[导入指南](Minitab导入与对标.md)。

随机化语义参考 Minitab 的[随机化选项](https://support.minitab.com/zh-cn/minitab/help-and-how-to/quality-and-process-improvement/measurement-system-analysis/how-to/gage-study/create-gage-r-r-study-worksheet/perform-the-analysis/specify-the-randomization-options/)及[工作表随机化说明](https://support.minitab.com/zh-cn/minitab/help-and-how-to/quality-and-process-improvement/measurement-system-analysis/supporting-topics/gage-r-r-and-wheeler-s-emp-studies/worksheet-randomization-for-a-gage-r-r-study-or-a-wheeler-s-emp-study/)。

## 导出文件名变量

方括号表示变量，区分大小写；括号外的字符原样保留。月份是`[MM]`，时、分、秒是`[H]`、`[M]`、`[S]`，均补足两位；不支持 `[HH]`、`[MIN]` 和 `[SS]`。`[[`和`]]`分别输出字面量`[`和`]`。变量仅作用于 CSV 文件名，目录不展开。

| 变量 | 中文等价变量 | 含义 |
|---|---|---|
| `[YYYY]`、`[YY]` | — | 四位、两位年份 |
| `[MM]`、`[DD]` | — | 月份、日期 |
| `[H]`、`[M]`、`[S]` | — | 24 小时制小时、分钟、秒 |
| `[MS]` | — | 三位毫秒 |
| `[TIMESTAMP]` | `[时间戳]` | Unix 时间戳，秒，从 1970-01-01 UTC 起算，例如`1792850892` |
| `[DATE]` | — | `2026-10-24` |
| `[TIME]` | — | `22-08-12` |
| `[DATETIME]` | — | `2026-10-24_22-08-12` |
| `[OPERATORS]` | `[人员数量]` | 人员数量 |
| `[REPLICATES]` | `[测量次数]` | 测量次数 |
| `[PARTS]` | `[产品件数]` | 产品件数 |
| `[USL]`、`[LSL]` | `[上规格限]`、`[下规格限]` | 规格限；未设置为`NA` |
| `[CENTER]` | `[数据中心]` | 中心设定值；留空时取实际数据均值 |
| `[MULTIPLIER]` | `[研究变异倍数]` | 研究变异倍数 |
| `[SEED]` | `[随机种子]` | 本次实际使用的种子，自动种子也输出实际值 |
| `[DP]` | `[小数位数]` | 数据输出小数位数 |
| `[EV_PCT]` | `[EV实际值]` | EV/TV%的实际值 |
| `[AV_PCT]` | `[AV实际值]` | AV/TV%的实际值 |
| `[GRR_PCT]` | `[GRR实际值]` | GRR/TV%的实际值 |
| `[PT_PCT]` | `[PT实际值]` | P/T%的实际值；不可计算为`NA` |
| `[NDC]` | `[ndc实际值]` | 实际 ndc；不可计算为`NA` |
| `[VERSION]` | `[程序版本号]` | 程序版本号，例如`1.0.0` |

百分比指标保留两位小数，不含百分号，与复核区显示一致；数据和计算精度不受文件名格式影响。研究参数、种子和指标来自已生成结果；参数变量中的数值使用小数点`.`，不使用系统区域的小数逗号。每次导出开始时取一次电脑本地时间，重名重试不改变这一时刻。保存配置保留模板原文。

帮助页中的变量名称可点击复制，复制内容包含方括号；英文、中文名称各自独立复制。成功后仅在固定底部状态栏提示，不弹窗、不改变布局。时间戳变量列在毫秒变量下方；它表示 Unix 秒数，与本地时区的显示格式无关，`[MS]`仍表示当前秒内的三位毫秒。

```text
MSA_Data_[YYYY]-[MM]-[DD]_[H]-[M]-[S].csv
→ MSA_Data_2026-10-24_22-08-12.csv

研究_[人员数量]人_[测量次数]次_[产品件数]件_GRR[GRR_PCT]_[DATETIME].csv
→ 研究_3人_3次_10件_GRR14.01_2026-10-24_22-08-12.csv
```

选项页的“同名文件”分段控件选择“追加序号”或“覆盖文件”。追加序号先尝试原名，重名时在扩展名前加入`_001`、`_002`，超过 999 后继续递增；最终写入使用原子不覆盖操作，并发导出也各自取得不同名称。覆盖模式使用原子替换。配置字段`output.existing_file`的值为`number`或`overwrite`，省略时默认`number`。

保存配置时检查变量名称、括号、非法字符及 Windows 保留名；导出时再次检查展开后名称和长度。错误时不生成文件、不弹窗，底部提示失败，日志给出具体原因。选项页只提供输入与重名策略控件，变量表、示例和规则统一放在软件帮助页。

文件名上限为 255 个 UTF-16 代码单元，扩展名和追加序号均计入；需要自动编号时应预留 `_001` 等后缀的空间。原子写入采用同目录的独立短临时名称，合法的长文件名不会因为临时名称拼接而超出组件长度上限。

## CLI 命令行使用

### 快速开始

在 `msa_cli.exe` 所在目录打开 PowerShell。以下第一条命令生成 3 位操作员、每件重复测量 3 次、10 件部件的数据；第二条用 ANOVA 复算**同一份数据**：

```powershell
.\msa_cli.exe --no-config --lsl 9 --usl 11 --seed 123 --output ".\测量数据.csv"
.\msa_cli.exe --no-config --input ".\测量数据.csv" --method crossed_anova --report ".\方差分析报告.json"
```

生成命令会导出 CSV；`--input` 只分析输入文件，不生成新数据、不改写或重新导出输入 CSV。已有同名 CSV 或报告默认受保护；确认需要替换时添加 `--overwrite`。

查看完整参数、许可证或创建配置文件：

```powershell
.\msa_cli.exe --help
.\msa_cli.exe --license
.\msa_cli.exe --init --config ".\我的配置.json"
.\msa_cli.exe --config ".\examples\示例配置.json" --output ".\测量数据.csv" --report ".\复核报告.json"
```

`--init` 创建的默认配置没有规格限和参考尺度，不能直接作为完整生成方案。请编辑规格/尺度，或通过命令行补齐；也可使用项目随附的有效示例配置。

### 配置优先级与参数语法

CLI 与 GUI 共用配置校验、生成、分析和导出内核。业务参数的优先级为**内置默认值 → 配置文件 → 命令行覆盖**，与`--config`在命令中的位置无关。重复参数或别名以最后一次为准；未传入的字段保持配置值，配置未包含的字段补内置默认值。普通运行只读取配置，不把覆盖值写回文件；JSON 报告中的`config`是本次最终生效的完整配置。

未指定`--config`时读取 GUI 用户配置`%USERPROFILE%\MSA数据生成器\msa_generator.json`，文件不存在则使用内存默认值，不自动创建文件。指定`--config PATH`时要求该 JSON 文件存在。`--no-config`跳过用户配置，仅使用内置默认值和命令行覆盖，不能与`--config`同时使用。`--init`仅负责创建缺失的默认配置，保留现有文件，不接受业务参数、输出或报告参数。直接运行且无任何参数会返回 2，不自动生成文件。

以下业务参数均须提供一个值，支持`--参数 值`和`--参数=值`。枚举值区分大小写，布尔值使用 `true` 或 `false`，不能省略；`null`表示清空可选数值，不能用空字符串代替。含空格的路径、文件名模板加引号。研究参数的数值范围与 GUI 相同。下文“默认”均指内置默认值，用户配置可覆盖它。

### 研究设计与分析参数

| 参数 | 配置字段 | 值及含义 |
|---|---|---|
| `--operators` | `design.operators` | 操作员数，2 或 3；默认 3 |
| `--replicates`、`--trials` | `design.replicates` | 每位操作员对每件部件的重复测量次数，2 或 3；默认 3，两者为别名 |
| `--parts` | `design.parts` | 部件数，5～10；默认 10 |
| `--method` | `analysis.method` | `crossed_xbarr` 均值极差法（默认）；`crossed_anova` 方差分析法 |
| `--interaction` | `analysis.interaction` | ANOVA 交互项：`auto` 自动判断（默认）、`include` 保留、`exclude` 合并至重复性误差 |
| `--interaction-alpha` | `analysis.interaction_alpha` | 交互项检验显著性水平，0 < α < 1；默认 0.05，仅 `auto` 使用 |
| `--study-multiplier` | `analysis.study_multiplier` | 研究变异倍数 k，0.000001～100；默认 6 |
| `--analysis-tolerance` | `analysis.tolerance` | 分析容差宽度，1e−12～2e12 或 `null`（默认）；优先用于 P/T，不改变生成规格 |
| `--historical-sd` | `analysis.historical_sd` | 历史过程标准差，1e−12～1e12 或 `null`（默认） |
| `--historical-mean` | `analysis.historical_mean` | 历史过程均值，−1e12～1e12 或 `null`（默认，使用测量均值） |
| `--process-variation` | `analysis.process_variation` | `historical` 使用有效历史标准差（默认）；`study` 保留研究数据估计 |
| `--misclassification` | `analysis.misclassification` | `true/false`，默认 `false`；仅 ANOVA 且至少设置一个规格限时计算误分类概率 |
| `--confidence` | `analysis.confidence.enabled` | `true/false`，默认 `false`；计算 ANOVA 方差分量及派生指标置信区间 |
| `--confidence-level` | `analysis.confidence.level` | 置信水平百分数，0.01～99.99；默认 95，启用 MLS 时另受算法有效范围限制 |
| `--confidence-bound` | `analysis.confidence.bound` | `both` 双侧（默认）、`lower` 单侧下限、`upper` 单侧上限 |
| `--confidence-method` | `analysis.confidence.method` | `mls` 默认，或 `satterthwaite`；分别对应已验证的 Minitab MLS / JMP EMS 区间口径 |

Xbar-R 不单独估计部件与操作员交互作用，也不输出 ANOVA 表、置信区间或误分类概率。ANOVA 使用平衡交叉双随机效应 EMS 模型；`auto` 在交互项 P ≥ α 时合并该项的平方和与自由度，否则保留。负方差分量逐项置零。

EV、AV、GRR、PV、TV 均为标准差（1σ），研究变异为 k × 标准差。EV/TV%、AV/TV%、GRR/TV% 属于标准差比，不能与方差贡献率 `%Contribution` 混用。独立分析容差优先于双侧规格宽度；单侧规格按半个研究变异与均值到规格限的距离计算 P/T。历史过程、置信区间与软件差异的完整说明见[配置参考](配置参考.md)和[GUI 参数兼容与对标进度](GUI参数兼容与对标进度.md)。

置信区间仅适用于 ANOVA。`mls` 使用 Minitab MLS 近似，`satterthwaite` 使用 Satterthwaite 有效自由度近似；重复性采用卡方区间。报告提供方差分量、标准差、研究变异，以及可计算的 P/T 和 `%Process` 置信限；单侧区间未指定的一侧、无法可靠计算的边界输出 `null`。当前不提供 `%Contribution`、`%Study Var` 和 ndc 的比值置信区间。

现有 MLS 近似在低置信水平下不保证平方根分支有效，因此程序会拒绝域外配置并给出恢复提示。2 名操作员可直接填写的最低双侧/单侧水平为 36.537899%/68.268950%，3 名操作员为 26.424112%/63.212056%；详见[配置参考](配置参考.md)。默认 95% 不受影响。确需更低水平时，须显式指定 `--confidence-method satterthwaite`；程序不会静默更换算法。

复核已有交叉长表的 JMP EMS 置信限时，统一研究变异倍数、规格及过程来源，并选择 Satterthwaite。未读取配置且未指定算法时使用 MLS；普通运行则沿用最终配置。以下示例假定 `common.csv` 为 3 位操作员、每件重复测量 3 次、10 件部件的数据，在程序目录运行：

```powershell
.\msa_cli.exe --no-config --input ".\common.csv" --method crossed_anova `
  --interaction include --study-multiplier 5.15 --lsl null --usl 11 `
  --historical-mean 10.1 --historical-sd 0.5 --process-variation study `
  --confidence true --confidence-level 95 --confidence-bound both `
  --confidence-method satterthwaite --report ".\jmp_compare.json"
```

该命令只分析已有数据，不重新生成或重排记录。单侧研究变异显示与误分类历史参数口径仍需按[实测说明](GUI参数兼容与对标进度.md)比较，不能因置信限算法相同就认定所有输出相同。

| `--ev`、`--av`、`--grr`、`--pt`、`--ndc` | `targets.EV_pct/AV_pct/GRR_pct/PT_pct/ndc` | 各项指标约束，语法见下表 |

### 指标约束语法

每个指标参数接受一个完整约束（`VALUE`、`MIN`、`MAX`、`ERROR`替换为实际数字）：

| 约束值 | 含义 | 示例 |
|---|---|---|
| `none` | 不约束，清除该指标的旧约束 | `--pt none` |
| `target:VALUE` | 目标值，使用本次最终配置中的默认允许误差 | `--ev target:10` |
| `target:VALUE:ERROR` | 目标值及显式允许误差，0 表示精确目标 | `--ev target:10:0.1`、`--ndc target:9:0` |
| `between:MIN:MAX` | 闭区间 | `--grr between:10:20` |
| `at_most:VALUE` | 不高于 | `--av at_most:10` |
| `at_least:VALUE` | 不低于 | `--ndc at_least:5` |

指标参数会**替换整个旧约束**。例如配置含 EV 的显式允许误差，使用 `--ev target:10` 后不会继承该值，而是使用默认允许误差；`--ev none` 只清除 EV，其他未传入的指标保持配置值。ndc 的值、区间与允许误差均为整数，其他指标可用小数；百分比允许误差的单位为百分点。例如 `--ev target:10:0.1` 接受 9.9%～10.1%，不是相对误差 0.1%。

上述约束用于生成目标和结果复核。生成时，P/T 约束需要规格限或独立分析容差；严格模式至少需要一个规格限。缺少双侧规格或显式选择参考尺度时，须设置参考 TV_SD 或历史标准差。`--input` 不要求输入数据满足生成条件；约束未满足会记录在报告的 `checks` 中，不代表分析失败。

### CSV 输出与运行顺序

| 参数 | 配置字段 | 值及含义 |
|---|---|---|
| `--output-directory` | `output.directory` | 输出目录；`--output-directory=""`清空后使用默认配置目录 |
| `--filename` | `output.filename` | `.csv`文件名模板，支持帮助页中的全部变量 |
| `--existing-file` | `output.existing_file` | `number`同名追加序号；`overwrite`覆盖 |
| `--csv-format` | `output.format` | `default`、`minitab`、`spss`、`jmp19`、`origin`、`matlab` |
| `--run-order` | `output.run_order.mode` | `standard`不随机化；`all`全部随机化；`within_operator`操作员内部随机化 |
| `--randomize-operators` | `output.run_order.randomize_operators` | `true/false`，仅`within_operator`生效 |
| `--run-seed` | `output.run_order.seed` | 独立排序种子，1～9223372036854775807 整数或`null`自动 |
| `--store-standard-order` | `output.run_order.store_standard_order` | `true/false`，是否增加首列 StdOrder |

默认格式为带部件列号和操作员标记的宽表，忽略全部运行顺序选项；五种软件长表的运行顺序、Trial、独立种子和 StdOrder 规则与 GUI 相同。`--seed` 控制测量数据生成，`--run-seed` 控制导出排序，两者互不影响。固定种子复现还要求数据、生成/运行顺序配置及程序版本一致，且未被搜索时间上限提前截断。编码、分隔符和换行由 CSV 格式确定。

### 常用生成示例

覆盖 GUI 保存的配置，选择长表及固定随机运行顺序：

```powershell
.\msa_cli.exe --config "$env:USERPROFILE\MSA数据生成器\msa_generator.json" `
  --operators 2 --trials 3 --parts 8 `
  --csv-format minitab --run-order within_operator `
  --randomize-operators true --run-seed 321 --store-standard-order true `
  --output-directory "D:\MSA导出" --filename "研究_[DATETIME]_[SEED].csv" `
  --existing-file number --report ".\最终配置与复核.json"
```

不读取任何 JSON 文件，完全通过命令行生成和导出：

```powershell
.\msa_cli.exe --no-config --operators 3 --replicates 3 --parts 10 `
  --lsl 9 --usl 11 --compliance strict --center 10 --seed 123 --decimal-places 4 `
  --ev target:10:0.1 --av at_most:10 --grr between:10:20 --pt at_most:20 --ndc at_least:5 `
  --csv-format spss --run-order all --run-seed 321 --store-standard-order true `
  --output ".\测量数据.csv" --report ".\复核报告.json"
```

### 路径、同名文件与退出状态

显式 `--output` 是包含文件名的文件路径（可为相对或绝对路径），方括号不展开，忽略`output.directory`、`output.filename`和`output.existing_file`，但 CSV 格式及运行顺序仍按最终配置。默认不覆盖显式 CSV 或报告，替换需加`--overwrite`。省略`--output`时使用最终配置中的目录、文件名变量和同名策略；`--overwrite`优先于`--existing-file`，无论两者出现顺序如何。输出相对目录和空目录仍以默认配置目录为基准；无用户环境的脚本应指定显式`--output`或绝对`--output-directory`。

`--config`、`--input`、`--output`、`--report` 的相对路径均以当前工作目录为基准；这一规则与 `--output-directory` 不同。输入 CSV、导出 CSV 均不得与报告指向同一文件。覆盖保护在最终原子提交时也生效，能防止并发覆盖。报告保存失败时可能已有成功 CSV，命令返回 1 并保留 CSV。

| 退出码 | 含义 |
|---|---|
| `0` | 成功；`--input` 的指标复核未满足不改变成功状态 |
| `1` | 配置读取、生成、文件读写或执行过程错误；生成被 Ctrl+C 取消 |
| `2` | 参数错误，或预检查发现显式 CSV / 报告同名且未允许覆盖 |

成功生成或分析时标准输出为 JSON，错误写入标准错误；`--init`、`--help`、`--license` 输出文本。脚本应同时检查退出码和报告内容。搜索超时或次数耗尽不等于已证明数学上无解，应先核对约束、规格、参考尺度和小数位数，再调整搜索预算。

## 版本与验证

固定种子在同一原生版本、相同生成配置且未超时截断时可复现。搜索找到可行候选后，最多追加 120 次尝试以比较候选质量，同时受总体次数和时间预算约束。排序只重排完整记录，不参与数据生成随机数序列。

验证入口、执行结果和验证范围见[验证说明](验证报告.md)。已验证 Windows x64；Minitab 实测版本 22.6，覆盖 Xbar-R 及 ANOVA；五软件 ANOVA 范围见 [ANOVA 设计与五软件对标](ANOVA设计与五软件对标.md)和[GUI 参数对标记录](GUI参数兼容与对标进度.md)。其他 Windows 版本、Linux、macOS 及远程桌面未宣称验证支持。实测报告中的哈希绑定对应被测二进制，逐组机器证据保存在本地 build 目录，不随仓库或运行包分发。

## ANOVA 分析与已有数据复算

在“选项 → 分析”选择分析方法和交互项策略。默认 Xbar-R；ANOVA 采用平衡交叉双随机效应 EMS，自动模式按 α=0.05 决定是否合并交互。改变方法、交互项策略或 α 后需重新生成。结果区的“ANOVA 详情”与 CLI 报告提供方差分析和分量信息；Xbar-R 对应“分析详情”。

| CLI 参数 | 对应配置/含义 |
|---|---|
| `--method crossed_xbarr/crossed_anova` | 分析方法 |
| `--interaction auto/include/exclude` | 自动/保留/合并交互 |
| `--interaction-alpha VALUE` | 0<α<1，默认 0.05 |
| `--input CSV` | 仅分析既有宽表/长表，不生成、不改写 CSV；可配合`--report` |

参数仍优先于配置文件。分析既有 CSV 时，人数/次数/件数必须与数据相符；输入与报告不能同路径，不能同时指定`--output`。`--input`不会将指标不满足生成约束误报为无法分析。统计含义、五软件实测及原生接口范围见[ANOVA 设计与五软件对标](ANOVA设计与五软件对标.md)。
