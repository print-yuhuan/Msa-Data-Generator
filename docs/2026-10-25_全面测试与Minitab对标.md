## 生成数据与 Minitab 实测矩阵

`tests/test_minitab.ps1`默认生成 240 组数据，逐份由 Minitab 的`WOPEN`导入，再执行`GAGERR; ...; XBAR`复算。192 组固定基准另计，不作为 240 组新生成数据的一部分。

240 组覆盖 24 种设计：2/3 人×2/3 次×5～10 件。每种设计覆盖不同固定种子、零人员变异、区间约束和指定中心、宽松规格、无规格、单侧规格、研究变异倍数 5.15 及 6，并额外验证 0 位和 10 位小数；其余场景使用 4 位小数。

六种 CSV 格式各 40 份；长表覆盖标准顺序、全部随机化、操作员内部随机化、随机操作员顺序，以及四列/含 StdOrder 五列。Minitab 导入列以 17 位有效数字写出，核对记录无丢失或重复、人员/部件/Trial 及 StdOrder 对应正确、CSV 行序保留，以及测量值按 double 精确相等。默认宽表在 Minitab 中通过 STACK 转换成长表后分析，不改源 CSV。

## 统计口径与判据

环境应记录操作系统、Minitab 实际版本、构建类型及被测 EXE 哈希。统计口径为 SD/TV 百分比、配置中的研究变异倍数；双侧规格下容差为 USL−LSL。Minitab 的分析存储项及接口参见其官方[会话命令说明](https://support.minitab.com/en-us/minitab/session-command-help/)和[COM 自动化文档](https://support.minitab.com/en-us/minitab/media/pdfs/notranslate/Minitab_Automation.pdf)。

每组比较 GRR、EV、AV、PV、TV 的标准差及研究变异，GRR/TV%、EV/TV%、AV/TV%、ndc；双侧规格时另比较 P/T%。

```text
abs(程序值 − Minitab值) <= 1e-11 + 1e-9 × abs(Minitab值)
ndc：精确相等
导入测量值：按double精确相等
```

判据仅用于跨软件计算对标，不增加用户目标误差。PowerShell 回读 JSON 数值时显式转换为 double，与程序和 Minitab 的计算类型一致。

## GUI 与 CLI 文件一致性

本次真实单 EXE 测试使用独立用户配置和无关空工作目录，在程序目录中只保留 msa_generator.exe，实际生成并导出 90 条测量，再用相同配置及实际种子执行 CLI，CSV 逐字节一致。报告确认未释放字体文件、个人配置 SHA-256 未改变；证据及截图见[单文件运行验证](单文件运行验证.md)。

其他研究参数、默认宽表及带 StdOrder 随机长表可依[界面验收](界面验收.md)中的步骤进一步复核。GUI 文件一致性验证与 Minitab 批量脚本分别记录，不计入 240 份批量实测。

## 复现与证据

```powershell
cmake --build build --config Release --parallel 6
ctest --test-dir build -C Release --output-on-failure
powershell.exe -NoProfile -NonInteractive -STA -ExecutionPolicy Bypass -File .\tests\test_minitab.ps1
```

Minitab 脚本需要本机已安装且许可可用的桌面版，不加入常规 CTest 依赖。批量结果目录由`build/latest-minitab-comparison.txt`指向，其中`comparison.json`保存逐组结果、最大误差和二进制哈希；各组保留配置、程序报告、CSV、导入列、分析命令及 Minitab 结果。常规报告位于`build/test-output/`、`build/cli-test-output/`、`build/export-test-output/`及`build/release-test-output/`。

基准 SHA-256：`08815D5CB98D15D50F4741893875FFAE560B1D88AF53D05F0B9A124D4C2B8E2D`。测试数据与完整机器证据由`.gitignore`排除，测试脚本和必需基准随源码提供。验证范围为 Windows x64 及 Minitab Xbar-R；其他统计软件应用内导入、ANOVA/EMP、其他操作系统及 IME 不在该矩阵内。
